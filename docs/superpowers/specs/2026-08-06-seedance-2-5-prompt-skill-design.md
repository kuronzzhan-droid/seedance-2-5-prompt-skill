# Seedance 2.5 提示词 Skill 设计

## 目标

创建一个独立、通用、可安装的 `seedance-2-5-prompt` Skill，把即梦 Seedance 2.5 使用手册与已验证的视频提示词经验整理成稳定工作流，并发布到新的 GitHub 仓库 `seedance-2-5-prompt-skill`。

Skill 接收剧情、素材清单、生成模式、目标时长、声音要求和镜头要求，输出可直接粘贴到即梦的中文视频提示词与简短校验结果。Skill 不包含海崖王国角色、剧情、本地绝对路径或项目专属设定。

## 核心裁定

1. 时长、画幅比例、分辨率属于即梦界面参数。普通 4—30 秒生成提示词不写“全片30秒”“16:9”“720P”等参数式开头；目标时长由提交设置和时间戳终点共同表达。
2. 超长视频模式同样默认不复述界面参数；只有用户明确要求把参数写入正文时才加入。
3. 时间轴按剧情容量划分为若干连续、不重叠、无空隙的时间片，段数与长度由内容决定，不机械等分。
4. 时间段使用 `0—4秒：` 这种纯时间格式，不在时间后添加 `【邀请】` 等小标题。
5. 参考素材逐项声明“参考什么、不参考什么”，白模只承担被明确指定的运镜、动作、动线、站位、光影或节奏，不自动继承白模外观。
6. 提示词只保留模型必须知道的信息。参考图已经锁定的静态外观不重复描述；镜头、动作、说话人、音色、声音和连续性使用具体可观察指令。

## 支持范围

- 文生视频与图片参考生成
- 4—30 秒时间戳叙事
- 30—180 秒超长视频脚本
- 视频延长与无缝转场
- 智能编辑、高级编辑和局部修改
- 粗颗粒度、细颗粒度白模渲染
- 多角色映射与多人同框
- 音色、对白、环境音、音效和 BGM 控制
- 第一人称 POV 与第三人称电影镜头
- 多宫格分镜、关键帧和多模态素材引用

不负责自动操作即梦网页、生成图片、渲染 Blender 白模或上传视频任务。

```text
├── tests/
│   └── test_validate_prompt.py

```

- `SKILL.md`：模式判断、输入整理、写作顺序、输出契约和交付前检查。
- `official-guide.md`：对 Seedance 2.5 手册的精简转述，包括输入限制、时间戳、多模态、编辑、音频、多人、白模、转场和分镜。
- `prompt-patterns.md`：不同模式的结构模板与一个完整示例；模板不把平台参数写入提示词正文。
- `field-notes.md`：从既有项目中抽取的通用经验，包括指令密度、动作容量、连续手部、角色归属、音色相对锚、真实质感和常见翻车修复。
- `validate_prompt.py`：对成品提示词做确定性检查。
- `tests`：覆盖合格提示词和典型失败提示词。

## 工作流

1. 读取用户需求，先分离“界面参数”和“提示词内容”。
2. 识别生成模式，并只加载该模式需要的参考文件。
3. 建立素材映射表：素材编号、主体或功能、需要参考的维度、明确不参考的维度。
4. 用一句话确定主体、地点、事件、风格和镜头策略。
5. 按内容容量分配时间片；每段写可见画面、镜头、动作、台词和声音。
6. 末尾写必要的全局连续性与声音约束，避免大段泛化负向词。
7. 运行校验器并修复错误，再交付最终提示词。

## 输出契约

默认交付两部分：

1. `Seedance 2.5 提示词`：可直接复制的纯文本，不附解释性小标题，不写平台界面参数。
2. `校验`：列出模式、时间轴是否连续、素材是否完成映射，以及仍需用户在界面设置的参数。

如果用户明确要求“只给提示词”，只输出第一部分。

## 校验器规则

错误：

- 普通提示词出现参数式开头，如“全片30秒，16:9”或“视频时长30秒”。
- 时间段重叠、跳秒、倒序，或最后时间戳与目标时长不一致。
- 时间后出现 `【小标题】`。
- 白模提示词没有声明参考维度，或没有角色与模型的对应关系。
- 使用了素材编号但没有用途映射。

警告：

- 单个短时间片塞入多个复杂动作。
- 多角色段落没有点名动作归属或说话人。
- 同段同时要求固定镜头和移动镜头。
- 参考图已绑定角色却在正文重复长篇静态外观。
- 只有抽象风格词，没有可见材质、光线或物理表现。

## 测试策略

先建立典型失败用例，再实现校验器和 Skill：

1. 30 秒提示词含“全片30秒，16:9”、固定六段五秒和时间小标题。
2. 白模视频只写“参考动作”，没有说明运镜、站位和模型映射。
3. 多角色对话没有角色—音色绑定，台词与嘴部动作归属不清。
4. 合格的 30 秒第一人称白模提示词，使用不等长连续时间片、双手连续入画、角色映射和具体声音约束。

测试包括：Skill 结构验证、YAML/frontmatter 校验、Python 单元测试、示例提示词校验，以及公开仓库泄漏扫描。
