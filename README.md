# 兽人西幻短片的 AI 提示词技能包（Seedance 2.5 + GPT Image）

[English](README.en.md) | 简体中文

三个可以装进 Claude 等 Agent 工具的技能（Agent Skills），用来做**西幻题材、兽人（furry / kemono）角色**的 AI 图片和视频。主打**写实 CG 质感**，同时覆盖三渲二和手绘西幻两种画风；通用题材（广告、短剧、海报、产品图）也能用。

内容来自作者做兽人短片的实测，加上火山方舟官方提示词指南、官方 sd25-pe skill 和 OpenAI 官方指南；社区经验为辅。每条规则都标了依据：〔官方〕〔多来源〕〔单一来源〕〔推论〕〔作者实测〕。调研日期 2026-10-28，覆盖 **Seedance 2.5（4–30 秒，重点 30 秒）** 和 **GPT Image 2 / 2.5（Flare、Sunburst）**。

## 三个技能

| 技能 | 做什么 |
|---|---|
| `seedance-video-prompt` | 把想法、脚本、分镜或素材写成 Seedance 2.5 视频提示词，附素材清单、平台设置和台词草稿。兽人日语文戏、打戏和特写有专门的参考和 6 条 30 秒完整模板 |
| `gpt-image-prompt` | 把想法或参考图需求写成 GPT Image 提示词，附参数建议和下一轮修改指令。兽人设定图、表情表、口型表、给视频用的单视图参考和空镜有固定写法 |
| `kemono-short-film-craft` | 做兽人短片的整套做法：开工前的三道检查、角色从草图迭代到 4K 定稿、场景、把故事导成 30 秒分段、试片审片、剪辑和发布。标准来自作者反响最好的短片《一枚铜币》 |

三个技能各自独立，可以只装一个；做完整短片时三个一起用。

## 安装

- **Claude 网页版 / 桌面版**：把 `skills/zh/`（或 `skills/en/`）下的三个文件夹分别压缩成 zip，在技能（Skills）设置里上传。
- **Claude Code**：把这三个文件夹复制到 `~/.claude/skills/`（所有项目都能用），或某个项目的 `.claude/skills/`。
- **其他支持 Agent Skills 的工具**：放进该工具的 skills 目录。

装好后直接说需求，例如“给两个狼骑士写一条 30 秒的夜谈”“出一张德牧骑士的设定图”“帮我看看这个短片的故事能不能开工”。

## GPT Image 速查：10 条最有用的经验

1. **先写用途和画布，再写主体。** 把“一张 3:4 竖版的门店灯箱海报”放在最前面，模型才会先安排版式。
2. **具体名词胜过形容词。** “高级、8K、大师级”基本没用；换成 5–12 个具体物件 + 光源方向 + 3–4 个颜色。
3. **要出现的文字全部加引号、逐字给出，** 写清位置、字体气质、层级和出现次数。中文注明简体，日文注明日本汉字字形和假名，数字用阿拉伯数字。
4. **约束写成正向的“只有……”“保持……”。** 作者实测，负向写法会损伤细节。文字密集的海报可以例外，保留一句“除以上文字外没有其他文字”，这句经过本地实测，文字逐字正确。
5. **兽人角色先写身份卡：** 物种结构、毛色分区、眼睛、犬爪手（四指加一根拇指）、一个只属于他的特征，服装逐件写材质；体型交给参考图。
6. **设定图用固定版式：** 正面全身、背面全身、头部特写放在同一张图里，比例和原立绘一致；喂给 Seedance 前裁成单视图，去掉图上的文字。
7. **编辑 = 只改一处 + 保留清单。** 每轮都重写保留清单，一轮只改一件事。
8. **多张参考图要编号并分配角色**（图1 角色、图2 服装、图3 场景），并要求光影统一。
9. **参数放在参数里。** 尺寸、质量、透明背景在 API 里设置；ChatGPT 网页没有参数面板，就把画幅写进提示词。
10. **选模型：** 2.5 Flare 求快，2.5 Sunburst 求精。ChatGPT 网页偶尔会把模型降级，效果明显变差时新开对话。

## Seedance 2.5 · 30 秒速查：12 条最有用的经验

1. **30 秒不是把 10 秒拉长。** 拆成 5–9 个镜头（本技能的固定写法），或者 3–4 段一镜到底；用整数秒，从 0 连续写到 30。
2. **每段只推进一个变化，并写清看得见的结束状态。** 下一段从这个状态接着走。
3. **画幅、时长、分辨率不写进提示词，** 写在平台设置里（官方 sd25-pe）。时间段照写。
4. **只写正向描述，不自动加通用的负面约束**（作者实测和官方 sd25-pe 一致）。“无背景音乐”写成“声音只有环境声、动作声和台词”；官方的负向句只留作排障备用。
5. **一镜到底时，段与段的交界最容易被切开**（本地实测在第 7.4 秒）。第二段起每段开头写“镜头不停，继续……”，跨空间时写出镜头怎么穿过去。
6. **台词格式：** `角色名（日语，音色，情绪，对谁说）：{日文原文}`。每句只写一次，写在它发生的镜头里；一段只让一个人开口，其他人“闭着嘴静静听”。
7. **声音符号按官方：** 音乐用 ()，音效用 <>，台词用 {}，字幕用 【】。环境声要写到最后一秒。
8. **兽人不是动物：** 写物种结构和一个只属于他的特征；背景人物写明种族；写“单膝跪地，上身挺直”，不写“半蹲”。情绪写成耳朵、尾巴、视线的动作。
9. **站位按机位写前景和背景。** 只写“隔桌相对”，社区实测 9 次全部失败；写清每个镜头的前景和背景后，3 次全部成功。三人轮流说话容易放错说话人。
10. **反应写成因果链：** 触发 → 停顿理解 → 第一反应 → 身体跟上 → 余韵 → 结束状态。先让观众看清原因，再给反应特写。
11. **台词只用用户给的原文。** 用户没给原文时，技能给的“台词草稿”放在提示词外面，确认后再放进去。
12. **省钱试错：** 先出 480P 样片，满意再出 720P（2026-10 即梦 30 秒分别是 270 和 600 积分）；即梦默认是样片模式，出正式片前要手动切换。超过 30 秒就拆成多条，或者用“向后延长”接上。
