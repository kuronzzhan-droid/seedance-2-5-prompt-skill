## 安装

- **Claude 网页版 / 桌面版**：把 `v2/seedance-video-prompt/` 和 `v2/gpt-image-prompt/` 分别压缩成 zip（或 .skill）后，在技能（Skills）设置里上传。
- **Claude Code**：把这两个文件夹复制到 `~/.claude/skills/`（所有项目都能用），或某个项目的 `.claude/skills/`。
- **其他支持 Agent Skills 的工具**：放进该工具的 skills 目录。

装好后直接说需求，例如“给凯尔和杰拉德写一条 30 秒的夜谈”“出一张瓦胡德的设定图”。

## GPT Image 速查：10 条最有用的经验

1. **先写用途和画布，再写主体。** 把“一张 3:4 竖版的门店灯箱海报”放在最前面，模型才会先安排版式。
2. **具体名词胜过形容词。** “高级、8K、大师级”基本没用；换成 5–12 个具体物件 + 光源方向 + 3–4 个颜色。
3. **要出现的文字全部加引号、逐字给出，** 写清位置、字体气质、层级和出现次数。中文注明简体，日文注明日本汉字字形和假名，数字用阿拉伯数字。
4. **约束写成正向的“只有……”“保持……”。** 你实测过负向写法会损伤细节。文字密集的海报可以例外，保留一句“除以上文字外没有其他文字”，这句经过本地实测，文字逐字正确。
5. **兽人角色先写身份卡：** 物种结构、毛色分区、眼睛、犬爪手（四指加一根拇指）、一个只属于他的特征，服装逐件写材质；体型交给参考图。
6. **设定图用你的固定版式：** 正面全身、背面全身、头部特写放在同一张图里，比例和原立绘一致；喂给 Seedance 前裁成单视图，去掉图上的文字。
7. **编辑 = 只改一处 + 保留清单。** 每轮都重写保留清单，一轮只改一件事。
8. **多张参考图要编号并分配角色**（图1 角色、图2 服装、图3 场景），并要求光影统一。
9. **参数放在参数里。** 尺寸、质量、透明背景在 API 里设置；ChatGPT 网页没有参数面板，就把画幅写进提示词。
10. **选模型：** 2.5 Flare 求快，2.5 Sunburst 求精。ChatGPT 网页偶尔会把模型降级，效果明显变差时新开对话。

## Seedance 2.5 · 30 秒速查：12 条最有用的经验

1. **30 秒不是把 10 秒拉长。** 拆成 5–9 个镜头（你的固定写法），或者 3–4 段一镜到底；用整数秒，从 0 连续写到 30。
2. **每段只推进一个变化，并写清看得见的结束状态。** 下一段从这个状态接着走。
3. **画幅、时长、分辨率不写进提示词，** 写在平台设置里（官方 sd25-pe）。时间段照写。
4. **只写正向描述，不自动加通用的负面约束**（你的实测和官方 sd25-pe 一致）。“无背景音乐”写成“声音只有环境声、动作声和台词”；官方的负向句只留作排障备用。
5. **一镜到底时，段与段的交界最容易被切开**（本地实测在第 7.4 秒）。第二段起每段开头写“镜头不停，继续……”，跨空间时写出镜头怎么穿过去。
6. **台词格式：** `角色名（日语，音色，情绪，对谁说）：{日文原文}`。每句只写一次，写在它发生的镜头里；一段只让一个人开口，其他人“闭着嘴静静听”。
7. **声音符号按官方：** 音乐用 ()，音效用 <>，台词用 {}，字幕用 【】。环境声要写到最后一秒。
8. **兽人不是动物：** 写物种结构和一个只属于他的特征；背景人物写明种族；写“单膝跪地，上身挺直”，不写“半蹲”。情绪写成耳朵、尾巴、视线的动作。
9. **站位按机位写前景和背景。** 只写“隔桌相对”，社区实测 9 次全部失败；写清每个镜头的前景和背景后，3 次全部成功。三人轮流说话容易放错说话人。
10. **反应写成因果链：** 触发 → 停顿理解 → 第一反应 → 身体跟上 → 余韵 → 结束状态。先让观众看清原因，再给反应特写。
11. **台词只用你给的原文。** 你没给原文时，我给的“台词草稿”放在提示词外面，你确认后再放进去。
12. **省钱试错：** 先出 480P 样片（270 积分），满意再出 720P（600 积分）；即梦默认是样片模式，出正式片前要手动切换。超过 30 秒就拆成多条，或者用“向后延长”接上。
