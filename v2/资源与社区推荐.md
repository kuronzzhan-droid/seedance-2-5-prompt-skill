## 七、避坑

- **审核规避类：不采用。** ADC1920/AI-Short-Drama-Studio 带“绕过人脸审核”的文档，其余内容也像是批量生成的，整个跳过。MapleShaw/seedance2.0-prompt-skill（827★）里的运镜和镜头参考可以看，但它宣传的“审核规避清单”不采用。原创角色遇到的多半是误伤，处理办法见 Seedance 技能的“边界”和“翻车排查”。
- **商业推广：只看不信。** BeatAPI、Evolink 的“Seedance 2.5 工作流”是 API 转售商的推广；freestylefly/awesome-gpt-image-2 虽然有 35k★，但里面有大量带推广码的转售链接。
- **山寨站。** seedance.tv 等同名网站和字节没有关系，官方入口是即梦、Dreamina 和火山方舟。
- **SEO 攻略页：参数常常互相矛盾，以官方为准。** 例如 atlabs、cometapi、framia 等的 “Seedance 2.5 / GPT Image 2.5 指南”。
- **可能是 AI 批量生成的知识库：用前自己验证。** 62656456/ai-film-knowledge-base、MountainandSeaTech/ai-anime-production-kb。
- **pixiv「獣人」tag 是混合分级。** 退出登录或关闭 R-18 再浏览。

## 八、从这些资料里提炼的规则（写进 skill 的新版）

1. **反应写成因果链**：触发 → 停顿理解 → 第一反应 → 身体跟上 → 上一种情绪的余韵 → 结束状态。每一拍写 1–3 个当前景别看得清的细节，并写出幅度。把眉、眼、鼻、嘴逐项列出来，会变成表情包式的切换。
2. **站位按机位写前景和背景**：drama-skills 实测，只写“隔桌相对”成功 0/9，按机位写清前景和背景 3/3。三人各说一句的镜头，2.5 两次都放错了说话人。文戏尽量用两人构图，一个镜头只让一人开口。
3. **时间码是事件预算，不是剪辑点**：实测切点偏差约 ±0.3–0.5 秒，所以小数秒没有意义。对白的一镜到底长镜头，3 次都没能同时做到台词的时机和结尾的静默。
4. **首帧要锁死，用首尾帧模式**：在全能参考模式里写“@图片1作为首帧”只会相近，不会锁定。要接续上一条，优先用“延长”。
5. **画面里冒出字幕或标题时**，把提示词里的【】段落标题换成 ■ 或纯文字。
6. **日语台词里尽量别出现数字**：各家对数字该怎么写说法冲突，也都没有实测。
7. **镜头数量参考**：30 秒文戏约 5 个镜头，动画式约 6 个，动作戏约 9 个。每个时间窗至少约 3 秒；冲击帧这类 1 秒以内的瞬间写进同一个窗口里，不单独占一个时间段。
