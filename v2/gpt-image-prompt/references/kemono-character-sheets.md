# 兽人角色图：设定图、表情、口型、Seedance 参考与图中日文

## 什么时候读这份文件

给这位用户用 GPT Image 2 / 2.5（ChatGPT 网页或 Codex）出兽人角色图时读：角色设定图、表情表、口型表、喂给 Seedance 的单视图参考和空镜机位图、首帧和关键帧、带日文的漫画页。只读用得上的那一节。通用写法（文字、编辑、多图合成）在 SKILL.md 和 `templates.md`。两个技能一起装时，用户的完整角色表和踩坑在 seedance-video-prompt 的 `references/creator-profile.md`，视频里怎么用这些图（台词、吻部口型、分镜）在同目录的 `kemono-jp-drama.md`。

标注：〔官方〕OpenAI、火山方舟、小云雀的官方文档和官方 sd25-pe skill；〔多来源〕两个以上非官方来源一致；〔单一来源〕只有一个非官方来源；〔推论〕由资料推出，没有实测；〔用户记录〕用户自己的设定和踩坑总结；〔本地实测〕2026-10-28 在用户电脑上的一次生成。最后两种也是单一来源。

## 1. 用户的 GPT Image 写法和角色段

固定三段：【画风】→【画面/镜头】→【角色】〔用户记录〕；图里要有字时加一段【文字】〔推论，依据 OpenAI 的文字写法〕。

| 习惯 | 写法 | 来源 |
|---|---|---|
| 画幅写进正文 | 第一句写“横版 16:9”或“横版 21:9”：ChatGPT 网页没有参数面板。走 API（或能设参数的 Codex）时，像素尺寸和质量档放参数里；提示词里写“4K”改不了分辨率 | 用户记录；官方 |
| 外观逐个部位 | 物种结构 → 毛色分区 → 眼睛 → 手 → 脚 → 服装（逐件写材质和颜色）→ 只属于他的特征 | 用户记录 |
| 物种写成结构 | “完整的狼头和长吻部，全身覆盖黑毛，直立双足”。“兽耳、猫耳、ケモミミ”这类词会把脸拉成人脸 | 多来源 |
| 手 | 犬科（凯尔、杰拉德、瓦胡德）写“手是犬爪手，四根手指加一根拇指”；其他物种的手以图1为准 | 用户记录；按物种分是推论 |
| 脚和体型 | 赤足的角色单独写一句，脚以原画为准；体型只写“全身比例以图1为准”，不写体型形容词 | 用户记录 |
| 数量写死 | “三个视图”“两行三列共六格”“三到五个大色团”“文字只有以下两段” | 用户记录 |
| 画面干净 | 加“哑光平涂，细节少”。两条 2D 线和空镜适用；超写实的海崖主线要写实毛发，不加 | 用户记录；适用范围是推论 |
| 光 | 写光源在画外哪一侧；写“逆光”会在头顶出光晕（记录没写是哪个平台，图和视频都这样写） | 用户记录 |
| 正向写法 | 写想要的状态；要排除什么，就写“画面里只有___” | 用户记录：负向写法损伤细节 |
| 风格 | 写看得见的画法，不写画师、工作室或作品名：OpenAI 限制模仿在世画师的画风；即梦有带 IP 名的提示词被拦的社区报告 | 多来源（报道）；单一来源 |
| 神态 | 写耳朵、尾巴、视线、吻部、毛发的动作，不写“脸红”“眼睛一亮” | 用户记录 |
| 多张图 | 每张编号并写用途：“图1是杰拉德的原立绘，只照角色设计和全身比例” | 官方 |
| 标记 | 伤疤、刺青、晶体按身体部位和角色自身的左右写（“角色自身的左眼上方”） | 单一来源；减少左右颠倒是推论 |

角色段每张图整段写，同一个角色每次原样复制〔官方：复用角色参考并重申外观约束〕。档案没写的部位写“以图1为准”，不替用户补设定〔用户记录〕。凯尔在船上篇和深海篇穿黑色立领新年装（金色竹叶纹，系红腰带），那两篇里围巾在不在以参考图为准〔用户记录〕：

```text
凯尔：黑狼兽人，成年男性，完整的狼头和长吻部，全身覆盖黑毛，直立双足。眼睛：琥珀色。手是犬爪手，四根手指加一根拇指。只属于他的特征：红围巾。服装、毛色分区、吻部长短、耳形、脚和尾巴以图1为准；全身比例以图1为准。
杰拉德：白狼兽人骑士，成年男性，完整的狼头和长吻部，全身覆盖白毛，直立双足。眼睛：蓝色。手是犬爪手，四根手指加一根拇指。服装：蓝白披风，其余服装以图1为准。只属于他的特征：脸上的伤疤，位置和形状以图1为准。毛色分区、吻部长短、耳形、脚和尾巴以图1为准；全身比例以图1为准。
```

## 2. 三条系列线的画风行

| 系列 | 正文第一句 | 画法（所有图都写） | 场景光和色（只写进空镜、首帧、剧照） |
|---|---|---|---|
| 海崖主线 | 横版 16:9 | 超写实电影画面：像摄影机拍下的一帧；毛发层次写实，毛流方向清楚，长毛和短毛分区明显；布料、金属、皮革的纹理清楚 | 按场景写光源方位。第一人称：镜头就是“我”的视线 |
| 《兜风日》 | 横版 21:9 | 三渲二赛璐璐：毛色平涂，一层边缘清晰的阴影加少量高光，轮廓线干净 | 按场景写 |
| 《量身》 | 横版 21:9 | 手绘西幻插画，细墨线加淡彩 | 背景像动画电影的手绘背景；暖金色斜阳和光柱，近处暗、中景亮、远处偏淡紫蓝 |

- 画风内容来自〔用户记录〕。“像摄影机拍下的一帧”“布料、金属、皮革的纹理清楚”是把“超写实”翻译成看得见的特征〔推论〕；赛璐璐几条是赛璐璐上色看得见的特征〔多来源〕。
- 设定图、表情表、口型表、单视图只写“画法”一列，背景浅灰纯色，均匀的平光：带风格的背景会把光线带进后面的图〔单一来源〕，场景光留给空镜和首帧〔推论〕。白毛、银白鳞片的角色（杰拉德、波波的白鬃、赛伦）在纯白背景上轮廓容易糊，所以用浅灰〔推论〕。
- GPT 出图和 Seedance 视频写同一句画风行〔多来源〕。《兜风日》《量身》的参考图一定按画风行出：参考图偏写实、提示词又没强调画风时，视频会漂成写实〔官方 2.0〕。
- 毛发：写实的写“长度 + 质感 + 颜色 + 光照”，如“颈部是更长更蓬的毛，光源在画外左侧，在毛尖勾出细亮边”〔单一来源〕；赛璐璐的补“毛发画成成簇的尖角毛簇，边缘清楚”〔推论〕。

## 3. 角色设定图（固定版式）

用户的版式：同一张图里放正面全身、背面全身和头部特写，比例照原立绘，不能画矮〔用户记录〕。换系列只换【画风】的画法；画矮了用第 9 节的单点修改。

| 要点 | 做法 | 来源 |
|---|---|---|
| 原立绘当图1 | 写“图1只照角色设计和全身比例，画法按【画风】”。新角色没有原立绘：先出一张正面全身锚定图，认可后再出设定图 | 用户记录；官方（先做可复用的角色参考） |
| 防画矮 | 把版式写死：两个全身视图头顶、脚底对齐，从耳尖到脚底完整入画，各占画面高度约九成；身高、头身比、腿长与图1一致 | 用户记录；写法是推论 |
| 头部特写 | 四分之三侧面、嘴自然闭合、中性表情，之后能直接裁给 Seedance。长吻正对镜头显得过长，还会挡住眼睛 | 官方 2.0（大头照中性表情最佳）；多来源 |
| 背面 | 尾巴完整可见，长度和正面一致 | 多来源（构图要给尾巴留空间，检查尾根） |
| 画幅 | 横版 16:9：三个视图放得下，裁出的单格宽高比约 0.6，在 Seedance 的 0.4–2.5 以内 | 推论；范围是官方 |
| 不写字 | 默认不写名字和标注，裁出来就能喂 Seedance；给人看的标注版另存 | 官方（Seedance 不靠图上文字，参考图的文字会诱发字幕） |
| 锁设计 | 每次附上认可的那张，复述角色段，加一句“Same character, same facial features, proportions, and color palette as image 1.”；漂移了回到认可的那张重做，不在漂移图上接着改 | 官方（措辞改自官方示例）；多来源 |
| 清晰度 | 设定图信息密：走 API 用 2048×1152 加 high；某一格糊了只重做那一格 | 单一来源；尺寸符合官方规格 |

```text
【画风】横版 16:9，超写实电影画面：毛发层次写实，毛流方向清楚，长毛和短毛分区明显，布料和皮革的纹理清楚。浅灰纯色背景，均匀的平光。
【画面/镜头】一张角色设定图，同一张图里放三个视图：左边三分之一是正面全身，中间三分之一是背面全身，右边三分之一是头部特写（头部和少量颈部，四分之三侧面朝画面左侧，嘴自然闭合，中性表情，头部约占画面高度的一半）。两个全身视图同一比例，头顶和脚底对齐在同一条水平线上，从耳尖到脚底和整条尾巴完整入画，各占画面高度约九成；背面视图里尾巴完整可见，长度和正面视图一致。三个视图的身高、头身比和腿长与图1一致。画面里只有这三个视图和浅灰背景。
【角色】图1是杰拉德的原立绘，只照角色设计和全身比例，画法按【画风】。（第 1 节的杰拉德角色段）Same character, same facial features, proportions, and color palette as image 1.
```

## 4. 表情表：耳朵、尾巴、吻部

| 要点 | 做法 | 来源 |
|---|---|---|
| 格数 | 3–6 个表情，从认可的设定图出。格子小了会糊：只重做糊的那一格，或者拆成两张、每张三格 | 多来源；重做一格是单一来源，拆张是推论 |
| 逐个通道写 | 每格写耳朵、尾巴、吻部（嘴角、牙、鼻梁）、眼睛和视线、颈毛。耳朵、尾巴和眉骨是兽人表情的主要工具 | 多来源（兽人设定图指南、兽人动画访谈） |
| 写停住的一瞬 | “尾巴甩到身体一侧停住”“双耳压平贴头”；静止图里写“摆动”“抖动”没有意义 | 推论 |
| 构图 | 每格从头顶到大腿中部，身体转四分之三，尾巴从身侧露出来；各格机位、景别、光线一样 | 推论 |
| 用在 Seedance | 主参考仍是中性闭嘴的头部图；某条片子要特定表情时，只把那一格裁出来附上。表情变化太大会让视频里的脸漂移 | 单一来源 + 推论 |

情绪写法和 Seedance 技能 `kemono-jp-drama.md` 1.6 是同一套，改成了静止的状态〔动物肢体语言和兽人动画访谈：多来源；对应到具体情绪：推论〕：

| 情绪 | 耳朵 | 尾巴 | 吻部、眼睛、毛 |
|---|---|---|---|
| 平静（基准格） | 自然竖立 | 放松下垂 | 吻部闭合，视线平视 |
| 警觉 | 竖直，一起转向声源 | 尾尖停在半空 | 瞳孔放大，视线投向声源 |
| 压着火 | 向后压平贴头 | 绷直 | 鼻梁起皱，上唇微抬露出犬齿尖，颈背毛竖起 |
| 低落 | 向两侧耷拉 | 低垂贴近腿 | 视线落向地面 |
| 安心 | 放松，向外微张 | 松松地垂向一侧 | 眼睛半眯，吻部放松 |
| 局促 | 一只向后转 | 尾尖翘起 | 视线移开，一只手摸着后颈 |

- 物种不同，通道不同〔推论；角色事实来自用户记录〕：猫科（波波、马格努斯、赞尼、瓦里克、肯尼V）快速甩尾多半是烦躁；赛伦用粉色耳鳍；基诺维用羽披，羽披炸起来＝心跳；罗尔夫脸上是硬质面甲，表情交给头的角度、肩和手；赛瑞斯、鱼龙、虎鲸、马族以参考图为准。
- 角色自己的表演钥匙〔用户记录〕和对应做法〔推论〕：凯尔“耳朵先暴露情绪”，加“嘴硬”格（吻部紧闭，耳朵却放低）；杰拉德“萌点全在耳朵和尾巴上”，他的表情表把变化集中在耳尾，吻部保持端正；波波“被照顾时愣半拍”，加“愣住”格（双耳竖直，一只手停在半空）。

```text
【画风】横版 16:9，超写实电影画面：毛发层次写实，毛流方向清楚。浅灰纯色背景，均匀的平光。
【画面/镜头】一张表情表，两行三列共六格，格子之间留细白边。每格是同一个角色从头顶到大腿中部的近景，身体转向四分之三侧面朝画面左侧，尾巴从身体一侧露出来；六格的机位、景别和光线一样，只有耳朵、尾巴、吻部、眼睛和颈毛的状态有变化。画面里只有六格角色和浅灰背景。六格从左上到右下：
1 平静：双耳自然竖立，尾巴放松下垂，吻部闭合，视线平视前方。
2 警觉：双耳竖直、一起转向画面左侧，尾尖停在半空，瞳孔放大。
3 压着火：双耳向后压平贴头，尾巴绷直，鼻梁起皱，上唇微抬露出犬齿尖，颈背的毛竖起。
4 嘴硬：吻部紧闭，嘴角向下，视线移向画面右侧，双耳却向两侧放低。
5 低落：双耳向两侧耷拉，尾巴低垂贴近腿，视线落向地面。
6 安心：双耳放松向外，尾巴松松地垂向一侧，眼睛半眯，吻部放松。
【角色】图1是认可的凯尔设定图。（第 1 节的凯尔角色段）六格是同一个角色，吻部长短、耳形、毛色分区和服装与图1一致。
```

## 5. 口型表：日语对口型参考

口型表不是喂给 Seedance 的“口型字典”：Seedance 会按台词给画面里看得见的嘴配口型〔推论〕。它的用处是定下这个角色张嘴的样子（唇线、下颌开合、露出哪些牙、舌头和口腔的颜色），出片后对照验收，需要时裁一格做参考。

| 格 | 对应 | 吻部 | 来源 |
|---|---|---|---|
| 1 闭 | 不说话、句末 | 吻部自然闭合，唇线连成一条 | 有限动画的三种基本嘴型：开、半开、闭〔单一来源〕 |
| 2 闭唇 | ま行；ば行、ぱ行 | 上下唇紧紧合拢 | ま行〔单一来源：兽人 3DCG 动画的 CG 导演访谈〕；ば、ぱ行〔推论〕 |
| 3 半开 | い、え，和多数音之间的过渡 | 下颌微微张开，露出上下犬齿的尖 | 三种嘴型〔单一来源〕；对应的元音〔推论〕 |
| 4 开 | あ | 下颌张开，露出上下犬齿和舌头前端 | 同上 |
| 5 收圆 | う、お | 嘴角向前收拢，开口小而圆 | 〔推论〕；多数口型方案按人类嘴型设计，长吻读起来不一样〔单一来源〕 |
| 6 低声 | 嘟囔、自言自语 | 吻部只张开一条缝 | 〔单一来源：同一访谈〕 |

- 六格同一个头：四分之三侧面，头的位置、眼睛和耳朵一样，只变吻部和下颌〔推论〕。短而宽的吻适合大开口，长吻的口型要收着画〔单一来源〕。牙写成这个物种的牙：“露出的是狼的犬齿”；有测评见过非人角色的牙在人牙和兽牙之间跳〔单一来源〕。舌头和口腔颜色以图1为准。
- 喂 Seedance：主参考用第 1 格或设定图的头部特写；张嘴、龇牙的图当主参考会让说话的口型不稳〔单一来源〕。想试第 4 格能不能稳住牙，只在 4–8 秒的单人口型测试镜里附上，写“只照张嘴时牙齿和口腔的样子”〔推论，没有实测〕。
- 喙（基诺维若是喙）和面甲（罗尔夫）做不出闭唇音，不做口型表，关键台词放到画外或背影〔推论〕。

```text
【画风】横版 16:9，超写实电影画面：毛发层次写实，吻部周围的短毛和唇线清楚。浅灰纯色背景，均匀的平光。
【画面/镜头】一张口型表，两行三列共六格，格子之间留细白边。每格是同一个角色的头部特写，从头顶到下巴下方，四分之三侧面朝画面左侧；六格的头部位置、角度、眼睛和双耳完全一样，只有吻部和下颌的开合有变化。画面里只有六个头像和浅灰背景。六格从左上到右下：
1 闭：吻部自然闭合，唇线连成一条。
2 闭唇：上下唇紧紧合拢。
3 半开：下颌微微张开，露出上下犬齿的尖。
```

- 预期：GPT Image 2 起日文明显变好〔多来源，报道转述 OpenAI〕；竖排 OpenAI 方面自己说还有课题〔单一来源，采访〕；小字和文字的精确摆放是官方列出的局限〔官方〕；没见到 2.5 修好竖排的公开证据。本地实测里 ChatGPT 网页一张 1024×1536 海报的三段中文逐字正确〔本地实测；是中文，不是日文〕。

- [ ] 三段【画风】【画面/镜头】【角色】，有字加【文字】；第一句写画幅
- [ ] 画风行按系列；设定图、表情表、口型表、单视图只写画法，浅灰纯色背景，平光
- [ ] 每个角色：物种结构 + 成年男性 + 档案里的外观 + 只属于他的特征；档案没写的写“以图1为准”；没有体型形容词
- [ ] 数量写死：三个视图、六格、N 段文字
- [ ] 提示词全是正向写法（扫一遍“不、没、无、避免、禁止”）
- [ ] 设定图：正面全身 + 背面全身 + 头部特写，比例照原立绘
- [ ] 喂 Seedance 的图：单张、纯色、图上没字、朝向和镜头一致、宽高比 0.4–2.5、不超过视频分辨率、和视频同画风
- [ ] 首帧：同画幅、动作开始之前、说话的人闭着嘴
- [ ] 日文：「」逐字，写了方向、位置、字体和次数；出图后逐字校对；给 Seedance 另出纯画面版
- [ ] 回复里附：走 API 时的尺寸和质量、默认假设、最可能用到的一条单点修改
