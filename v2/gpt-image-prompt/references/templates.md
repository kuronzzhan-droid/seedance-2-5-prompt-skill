# GPT Image 场景模板

用法：找到对应小节，套用模板，替换【】里的内容，删掉用不上的行。模板只是起点：保留结构，按用户需求增删。

## 目录

1. 写实人像 / 生活方式照片
2. 产品图 / 电商主图
3. 透明底产品抠图
4. 海报 / 广告（文字层级）
5. 信息图 / 科普图 / 流程图
6. UI 界面稿
7. 幻灯片 / 数据图表
8. Logo
9. 漫画 / 多格分镜 / 宫格
10. 角色设定图（一致性锚点）
11. 编辑类：换装、换背景、去物体、改光线天气、翻译、草图转渲染、风格迁移、局部换物
12. 多图合成
13. 给视频模型（Seedance 等）准备首帧和参考图
14. 结构化 JSON 写法（复杂产品渲染）
15. 英文通用骨架

## 1. 写实人像 / 生活方式照片

要点：写“谁在什么情况下拍的”；保留真实瑕疵；人物写景别、视线和互动；只用一个主导的拍摄框架。建议 1024×1536，medium。

```text
一张真实照片，【竖版 2:3】，【拍摄方式：如“朋友用手机随手拍下的瞬间”“杂志专访的自然光人像”】。
人物：【年龄段、外貌特征、发型、服装材质与颜色】，正在【动作】，视线【看向哪里 / 不看镜头】，【景别：半身 / 全身入镜】。
场景：【地点、时间】，背景里有【3–6 个具体物件】。
光线：【光源 + 方向，如“傍晚从左侧窗户斜射进来的暖光，在墙上留下窗框阴影”】。
保留真实的皮肤纹理、毛孔、发丝和衣服褶皱，比例自然；不要磨皮美颜、不要过度锐化、不要影棚感。画面中不要任何文字和水印。
```

示例：

```text
一张真实照片，竖版 2:3，像朋友用手机随手拍下的瞬间。一位六十多岁的修表师傅，花白短发，额头上推着一副放大镜，穿深蓝色旧工作服，正低头用镊子夹起一枚细小齿轮，没有看镜头，半身入镜。场景是老街上一间不到十平米的修表铺，玻璃柜台里摆着拆开的旧怀表，墙上挂着十几只走时不一的挂钟，台灯下有一杯冒着热气的茶。光线：午后从门口照进来的自然光，加上台灯的暖黄色点光。保留脸上的皱纹和手上的老茧，工作服袖口有磨损；不要磨皮、不要影棚布光。画面中不要任何文字和水印。
```

## 2. 产品图 / 电商主图

要点：锁定产品外形、材质和标签文字。有实物照片就作为参考图上传，并写“保持产品外形、颜色、标签完全一致”。道具要服务卖点。电商主图通常 1:1。

```text
一张商业产品摄影，【1:1 方图】，用于【电商主图 / 详情页首屏 / 社媒广告】。
主体：【产品名、外形、材质、颜色；标签上的文字“___”】，位于画面【中央偏下 / 右侧三分线】，约占画面【60%】。
（有参考图时）以图1中的产品为准，保持外形、比例、颜色、标签文字和 logo 位置完全一致。
场景与道具：放在【台面材质】上，周围有【2–4 个呼应卖点的道具，如“切开的青柠、冰块、薄荷叶”】。
光线：【柔光箱侧光 / 逆光轮廓光 / 自然窗光】，产品表面有【真实的高光 / 冷凝水珠 / 磨砂质感】，底部有自然的接触阴影。
配色：【3 个颜色】。背景【简洁 / 虚化】，右上角留出放卖点文字的空白（本图不放文字）。
不要额外 logo、不要虚构品牌名、不要水印、不要多余文字。
```

## 3. 透明底产品抠图

API 设置 `background=transparent`，格式 png 或 webp。

```text
把图1中的产品抠出来，放在完全透明的背景上，产品居中，四周留出适当边距。保持产品的形状、比例、颜色，标签文字清晰可读，不要改动产品本身。边缘干净，没有白边、光晕或残留背景；不要阴影、不要倒影、不要棋盘格、不要任何背景元素。
```

## 4. 海报 / 广告

要点：先版式后内容；所有文字加引号、逐字给出；写清层级（谁最大）。用“三眼测试”检查：第一眼认出主题，第二眼读懂卖点，第三眼看到细节。

文字槽位按重要性分配：最大 = 主题或店名，其次 = 卖点或优惠，再次 = 时间地点，行动号召可选。用户只给了店名、日期、优惠三句话，就只排这三句，不要硬凑。插画类海报要说清“纸张底色”和“场景”的关系（如“主视觉边缘用水彩晕染，淡出到米白纸底”），避免“纯色底”和“满版场景”互相矛盾。

印刷用途（贴门口、展架、易拉宝）：
- 按成品尺寸选画幅：60×90cm、80×120cm 的 KT 板是 2:3（API 可用 1536×2304）；A4/A3/A2 纸约 1:1.41（API 可用 1440×2032；ChatGPT 里选 2:3，留白边后裁切）；80×200cm 易拉宝是 2:5（API 可用 1152×2880）。
- 文字离边缘至少留出画面宽度 5% 的安全距离。
- 模型输出的长边通常在 1536–2560 像素左右（更大的尺寸属于实验性），打印 A3 及以上建议先用超分工具放大，或请打印店确认清晰度。
- 二维码、条形码不要让模型画，后期贴真实的。

```text
设计一张【竖版 2:3（门店打印）/ 3:4（小红书）】的【活动 / 新品 / 品牌】海报，用于【门店展架 / 地铁灯箱 / 小红书】，远看也能读清。
版式：上方三分之一是标题区，中部是主视觉，底部是信息栏；四周留足边距，文字和图像不重叠。
主视觉：【主体 + 动作 + 环境 + 光线】。
风格：【具体风格锚点，如“新中式、克制留白、宣纸纹理”】，配色【3–4 个颜色】。
只渲染以下文字（简体中文，笔画清晰，无错别字）：
- 标题：“【标题】”（最大号，【字体气质】，【颜色】，居中）
- 副标题：“【副标题】”（标题下方，中号）
- 信息：“【时间 / 地点 / 价格】”（底部信息栏，小号但清晰）
- 行动号召：“【CTA】”（右下角）
每段文字只出现一次；除此之外不要任何文字、不要乱码、不要虚构的 logo 或赞助商标志。
```

示例：

```text
设计一张竖版 3:4 的奶茶新品海报，用于门店灯箱，远看也能读清。版式：上方三分之一是标题区，中部是主视觉，底部是价格栏，四周留足边距。主视觉：一杯透明塑料杯装的冷泡乌龙奶茶，杯壁挂着细密的水珠，杯中漂着几朵金色桂花，背景是虚化的深秋银杏树和暖橙色的夕阳光斑。风格：日系清新商业摄影，配色为奶咖色、桂花金、墨绿。
只渲染以下文字（简体中文，笔画清晰，无错别字）：
- 标题：“桂花冷泡乌龙”（最大号，圆润粗黑体，深咖色，居中）
- 副标题：“秋天的第一口清甜”（标题下方，中号细体）
- 价格栏：“中杯 16元｜大杯 19元”（底部，白字配墨绿色圆角底条）
每段文字只出现一次；除此之外不要任何文字、不要乱码、不要虚构 logo。
```

## 5. 信息图 / 科普图 / 流程图

要点：写明受众和要讲清的流程；先定版式分区；标签逐字给出；图标风格统一扁平；箭头方向清楚。密集小字用 high。数据只用真实或用户提供的。

```text
一张【竖版 2:3】的【主题】信息图，面向【受众，如“小学高年级学生”】，目的是讲清【流程 / 结构 / 对比】。
版式分区：顶部标题“【标题】”；中间按【从上到下 / 从左到右】排列【N】个步骤，每步一个扁平图标 + 编号 + 短标签；底部一句总结“【总结】”。
各步骤标签（逐字渲染）：1“【】” 2“【】” 3“【】” 4“【】”。
风格：扁平矢量、统一线宽的图标、白色背景、【2–3 个主色】，箭头清楚地指向下一步，标签字号足够大。
不要多余装饰、不要小到看不清的文字、不要编造没有提供的数据。
```

## 6. UI 界面稿

要点：把产品当作已经上线来描述；写层级、间距、真实的界面元素和像真的数据；避免“概念图”一类措辞；用虚构的产品名。

```text
一张真实的手机 App 界面截图（不是概念图），iPhone 竖屏，产品名“【虚构产品名】”，是一款【用途】应用。
页面：【首页 / 详情页 / 结算页】。从上到下：顶部导航栏显示“【页面标题】”；【卡片 / 列表 / 图表】展示【具体数据，如“本月支出 ¥3,280.50”】；主按钮文字“【按钮文字】”；底部 Tab 栏依次是“首页”“统计”“我的”。
设计语言：【浅色 / 深色】主题，主色【颜色】，圆角卡片，8pt 网格间距，清晰的系统字体，图标线宽统一。
文字清晰对齐，无乱码；不要设备以外的装饰元素，不要真实品牌。
```

## 7. 幻灯片 / 数据图表

要点：横版（如 1536×864 或 2048×1152）+ high；写清交付物、层级和真实数字；要极简就明确禁止剪贴画、库存照片、渐变和阴影。

```text
一页 16:9 的汇报幻灯片，标题“【标题】”（左上，大号粗体）。
左侧 60% 是【柱状图 / 折线图】：横轴“【横轴名】”，纵轴“【单位】”，数据：【A 12、B 18、C 25】，每根柱子顶端标数值。
右侧 40% 是三条要点（逐字）：“【要点1】”“【要点2】”“【要点3】”。
右下角小字脚注：“数据来源：【来源】”。
风格：白底、深蓝和灰两种颜色、充足留白、细线坐标轴；不要剪贴画、不要库存照片、不要渐变和阴影、不要多余装饰。
```

## 8. Logo

要点：写品牌性格和使用场景；扁平、简洁、可缩放；透明底（参数 transparent）；用 `n` 一次出多个方案。

```text
为品牌“【品牌名】”设计一个原创 logo。品牌是【行业 / 产品】，性格【如“温暖、可靠、带一点俏皮”】。
图形：【核心意象，如“一片叶子和对话气泡结合”】，扁平、几何、线条干净，缩小到 16 像素也能辨认。
文字部分“【品牌名】”使用【字体气质】，和图形【左右 / 上下】组合。
配色不超过 2 种：【颜色】。透明背景，四周留足边距；不要背景、不要阴影和立体效果、不要水印、不要其他文字。
```

## 9. 漫画 / 多格分镜 / 宫格

要点：先说格数和阅读顺序；每格只放一个视觉节拍；写明共享的角色特征、配色和光线；对白逐字给出。

```text
一张【竖版】【4 格】漫画，从上到下阅读，每格之间有清晰的白边。统一画风：【风格】；统一角色：【角色锚点描述】。
第1格：【景别】，【动作 / 表情】，对白气泡“【台词】”。
第2格：……
第3格：……
第4格：【反转 / 笑点】，对白气泡“【台词】”。
每格的角色外观、服装、配色保持一致；只出现以上对白，不要其他文字。
```

## 10. 角色设定图（一致性锚点）

用它作为之后所有场景的参考图。纯白背景最稳。

```text
一张角色设定图（character reference sheet），横版 16:9，纯白背景。
角色：【名字】，【年龄 / 物种】，【脸型、五官、发型发色】，【身材比例】，【服装：每件的材质和颜色】，【标志性配饰 / 道具】。
排布：左侧是正面、侧面、背面三视图全身站姿（同一比例）；右上方是 4 个表情特写（开心、惊讶、生气、难过）；右下方是 3 个配饰或道具的细节特写。
统一的平光照明，没有投影；画风【写实 / 3D / 日系动画】；除了角色名“【名字】”不要任何文字。
```

给视频模型用时，再把正面、侧面、背面各单独生成一张单视图图片。视频模型理解独立的单视图图片比理解拼图更稳。

## 11. 编辑类

通用句式：**只改【X】 + 其余保持不变 + 保留清单 + 禁止项**。每轮重复保留清单，一轮只改一件事。

换装（虚拟试穿）：

```text
把图1中人物的服装换成图2中的【外套 / 连衣裙】。保持人物的脸、肤色、体型、发型、表情和姿势完全不变；衣服的版型、颜色、面料纹理与图2一致，并按人物姿势自然垂坠、产生褶皱，光线和阴影与原图一致。背景、机位、构图不变；不要添加配饰、文字、logo 或水印。
```

换背景 / 把人物放进新场景：

```text
把图1中的人物放到【新场景】中。保持人物身份、五官、发型、服装和姿势不变。按新场景的光源方向重新匹配人物的光照、皮肤反光和脚下的接触阴影，透视和比例合理，看起来像同一次拍摄的真实照片；不要贴图感、不要电影调色。
```

去除物体：

```text
去掉【画面右侧路人手里的红色雨伞】，用合理的背景补全。其他任何地方都不要改动。
```

改光线 / 天气：

```text
把这张照片改成【下着小雪的冬日傍晚】：冷蓝灰色调，屋顶和地面有薄薄的积雪，空中有飘落的雪花。只改变环境光线和天气，建筑、人物、物体位置、机位和构图完全不变。
```

翻译图中文字：

```text
把图中所有英文翻译成简体中文。只替换文字内容，保持原有的字体风格、字号层级、颜色、位置和排版，不要重新排版，其他视觉元素完全不变。
```

草图转渲染：

```text
把这张手绘草图渲染成【写实的室内效果图】。严格保持草图中的布局、比例、透视和每个物体的位置；加入真实材质（【橡木地板、亚麻沙发、黄铜灯具】）和【午后自然光】。不要添加草图中没有的物体或文字。
```

风格迁移：

```text
用图1的风格（【配色、笔触、纸张纹理、颗粒感】）来画【新主体 / 新场景】。只借用风格，不复制图1的构图和内容；白色背景，不要添加额外元素。
```

局部换物：

```text
把画面中所有的椅子换成【浅色实木椅】。保持机位、光线、阴影、桌子和其他所有物品不变。
```

## 12. 多图合成

```text
图1：【人物照片】（保留脸、发型、身材）；图2：【服装】（保留版型和面料）；图3：【场景照片】（作为背景）；图4：【风格参考】（只取色调和颗粒感）。
生成一张【竖版 2:3】的写实照片：图1中的人物穿着图2的服装，站在图3的场景中【位置 / 动作】，整体色调参考图4。
统一光源方向为【方向】，人物与环境的透视、比例、接触阴影和反光一致；不要改变人物五官；不要添加文字和 logo。
```

## 13. 给视频模型（Seedance 等）准备首帧和参考图

- 首帧图：画幅和视频一致（视频是 16:9 就出 16:9）；构图就是视频第一秒的画面；人物处在动作开始之前的状态；图上不要放文字。
- 角色参考：正面、侧面、背面各出一张单视图图片，纯色背景、平光、全身完整、无文字。这比三视图拼图更适合视频模型。
- 不要过度锐化，不要杂乱的背景。图片分辨率不必高于视频的输出分辨率（Seedance 官方提示过高可能产生指纹状纹理）。
- 首帧和尾帧要同画幅；尾帧应是首帧经过动作后能合理到达的状态。

## 14. 结构化 JSON 写法（复杂产品渲染）

需要同时控制环境、主体、材质、灯光、粒子和动态元素时，类 JSON 结构更好控制。键名描述视觉子系统，值写具体、看得见的约束：

```text
{
  "画布": "2:3 竖版，商业广告摄影，前景锐利，微观质感可见",
  "环境": {"背景": "暖橙色渐变影棚背景", "灯光": "右上方柔光箱 + 左后方轮廓光", "氛围": ["漂浮的细小水雾", "柔和的焦外光斑"]},
  "主体": {"产品": "磨砂玻璃瓶装冷萃咖啡", "材质": ["磨砂玻璃", "瓶身冷凝水珠", "牛皮纸标签"], "构图": "瓶身倾斜 15°，位于画面中央偏下"},
  "动态元素": [{"对象": "咖啡豆", "状态": "悬浮在空中"}, {"对象": "咖啡液", "状态": "从瓶口溅起的浓稠弧线"}],
  "文字": "标签上只有“COLD BREW”字样，其余不要任何文字",
  "避免": ["廉价电商横幅感", "塑料 CG 质感", "虚构品牌 logo"]
}
```
