# GPT Image 提示词优化

目标：把用户“想要的图”翻译成 GPT Image 能稳定执行的**视觉规格书**。

为什么这样写：从 GPT Image 2 开始，生成流程里加入了推理，模型会完整读懂长段文字并按字面执行。所以好提示词更像一份设计 brief（用途、画布、内容、文字、约束都交代清楚），而不是一串风格词。Stable Diffusion / Midjourney 时代的 “masterpiece, best quality, 8K, trending on artstation” 对它基本无效，只会稀释真正重要的信息。

这个技能按一位用户定制：他主要画说日语的成年男性兽人角色（设定图、表情表、剧照），再把图喂给 Seedance 做视频。给他画角色之前，先读 `references/creator-profile.md`（个人档案，公开仓库里没有；本地使用时自己放进 references/，找不到就跳过，按用户在对话里给的信息写）和 `references/kemono-character-sheets.md`。给别人写通用题材时，跳过这些即可。

## 交付格式

默认这样回复：

1. **提示词**：放在一个 `text` 代码块里，可直接粘贴。
2. **参数建议**：模型 / 尺寸（像素）/ 质量档 / 背景 / 张数。这些在 API 参数里设置，不写进提示词。用户在 ChatGPT 网页或 App 里出图时基本调不了这些：省掉这一项，把画幅写进提示词，只提界面里真有的功能（见“模型与参数速查”的最后一条）。
3. **默认假设**（如有）：一行列出你替用户做的选择，方便他改。
4. **下一轮怎么改**：1–2 条单点修改指令，预判最可能出问题的地方（通常是小字、手、品牌元素、人物一致性）。兽人角色常见的问题和改法，都写成正向的“只改这一处”：被画成兽耳人类 → “只把角色的头部改成完整的狼头和长吻部，脸部覆盖毛发；服装、姿势、构图、光线保持原样”；手指数不对 → “只把双手改成犬爪手，四根手指加一根拇指，其余保持原样”；识别特征换了位置 → “只把伤疤移回图1里的位置，其余保持原样”。

用户说“直接给提示词 / 只要提示词 / 提示词就行”时用精简版：不提问，代码块放最前，后面最多跟 2–3 行（默认假设 + 最可能用到的一条修改指令）。只有用户明确说“别解释、只要代码”时，才只给代码块。

提示词语言跟随用户（中文用户默认写中文）；用户或其工作流需要英文时写英文。要渲染在图上的文字永远保持用户给的原文，不翻译、不润色。

## 工作流

### 1. 判断任务类型

| 类型 | 典型需求 | 第一验收项 |
|---|---|---|
| 文生图 | 从零生成照片、插画、渲染图 | 主体、构图、风格 |
| 文字密集型 | 海报、广告、信息图、UI、幻灯片、图表、菜单、包装 | 每个字都对，层级清楚 |
| 编辑 | 只改一处：换装、换背景、去物体、改光线天气、翻译文字 | 改的地方对，其余不变 |
| 多图合成 | 人物 + 服装 + 场景 + 风格多张参考 | 每个元素来源正确，光影统一 |
| 系列一致性 | 绘本、分镜、电商套图、同一角色多场景 | 角色/产品跨图一致 |
| 兽人角色（这位用户） | 设定图、表情表、剧照、给视频用的单视图参考和空镜 | 物种结构、识别特征、手的结构、比例和原立绘一致 |

### 2. 只补会改变结果的缺口

值得问的只有：用途/投放位置、画幅、**必须出现的文字原文**、必须保留的身份或品牌元素、风格方向。一次最多问 3 个；用户说“直接写”就用默认值，并写进“默认假设”：

- 画幅：门店打印的海报、人像、手机竖屏 → 2:3；小红书配图 → 3:4；横版场景、幻灯片、封面 → 16:9；社媒方图、Logo → 1:1。这位用户的系列画面：海崖主线 16:9，《兜风日》《量身》21:9（见 creator-profile.md）。要打印到 A 系列纸张或易拉宝时，看 `references/templates.md` 第 4 节的印刷要点。
- 风格：用户给了氛围词（温馨、高级、科技感、国潮……）时，先按氛围词选媒介；没给再按用途推断（广告 → 商业摄影；科普 → 扁平矢量信息图；UI → 真实产品截图质感）。氛围词本身模型看不懂，要翻译成具体的旋钮，例如：
  - 温馨 → 暖色侧光、米白纸纹、圆体或手写字，水彩彩铅插画或暖光生活摄影
  - 高级 → 大面积留白、低饱和配色、细衬线字体、单一光源
  - 科技感 → 深色背景、冷色点缀、几何网格、发光细线、无衬线字体
  - 国潮 → 朱红、墨黑和金色，书法或宋体标题，传统纹样做边饰
- 文案：用户给了就逐字用；用户没给时不要自己编大段文案，可以放一个占位标题并提醒替换，或做无字版。
- 日期、价格这类事实照原文用。日期和今天对不上（比如已经过去了），或者缺年份、星期时，不要自行补全，在回复里用一句话请用户确认。

### 3. 按结构写

官方推荐顺序：**用途与画布 → 场景/背景 → 主体 → 关键细节 → 约束**。复杂需求用带标签的分段；简单需求一两句话就够。原则是尽量短，但该具体的地方必须具体。

通用骨架（按需删减，不必每栏都填）：

```text
【用途/画布】一张 2:3 竖版的___（海报/产品主图/信息图/写实照片…），用于___。
【场景】地点、时间、天气；环境里 5–12 个具体物件。
【主体】是谁/是什么、外观、姿态、动作、视线、与物体的互动；在画面中的位置和大小。
【构图与镜头】景别、视角/机位、前中后景、留白位置；拍摄方式（如“手机随手拍”“85mm 人像镜头感”）。
【光线与色彩】光源类型 + 方向（如“光源在画外左侧的窗户，柔和晨光”）；3–4 个具体颜色的色板；关键材质。
【风格/媒介】具体、有边界的风格锚点（如“瑞士网格排版 + 丝网印刷质感”“日系赛璐璐动画”）。
【文字】画面上的文字只有以下几段：标题“___”（位置、字体气质、颜色、层级）；副标题“___”……；每段只出现一次。包装、杯子、招牌、桌布这些表面保持素面。
【约束】必须保留___；再针对模型最容易犯的默认错误，加 1–3 条正向的“只有……”“保持……”，例如“画面里的品牌标识只有图1产品上原有的那一个”。
```

约束先写成正向。这位用户实测过，负向写法（不要 / 没有 / 避免）会损伤细节；OpenAI 官方则建议把排除项直接写进提示词（API 没有 negative prompt 参数）。两者这样折中：角色图和场景图全部用正向写法；文字密集型的图（海报、信息图、UI）默认保留一句官方式的排除句“除以上文字外没有其他文字”，因为本地海报实测带着这句时文字逐字正确；其余情况只在正向写法压不住某个默认错误（假 logo、乱码小字、多余人物）时，才补 1–2 条排除句，并在回复里标明这是负向写法。

这位用户出兽人角色图时，习惯分三段：【画风】【画面/镜头】【角色】。画幅写在【画风】开头（ChatGPT 网页没有参数面板）；三条系列线的画风行从 creator-profile.md 原样复制。外观逐个部位写：毛色分区、眼睛、手、服装材质；数量写死，例如“三到五个大色团”；想要画面干净，就写“哑光平涂，细节少”〔用户记录〕。

### 4. 叠加场景专项要点

写到具体类型时，打开对应的参考文件，只读需要的那一节：
- 兽人角色的身份卡、设定图、表情表、给 Seedance 用的单视图和空镜、日文排版：`references/kemono-character-sheets.md`
- 写实人像、产品/电商、透明抠图、海报广告、信息图、UI、幻灯片图表、Logo、漫画分镜、角色设定、编辑类、多图合成、给视频模型做参考图、结构化 JSON 写法、英文骨架：`references/templates.md`

### 5. 交付前自检

- 提示词里的画幅和参数尺寸一致吗？（写了 16:9 就别配 1024×1536）
- 每个要显示的字都在引号里、逐字正确、有位置？写了“每段只出现一次”吗？
- 还有空洞形容词吗（高级、好看、高质量、8K、大师级）？换成看得见的名词、材质、光线。
- 有没有自相矛盾？（“极简”又“细节丰富”；“俯拍”又“仰视”；“纯白背景”又“城市街景”）
- 编辑类：是否写了“只改 X” + 完整保留清单？是否一次只改一件事？
- 约束是不是都写成了正向的“只有……”“保持……”？确需排除的默认错误是否最多 1–2 条，并在回复里标明了是负向写法？
- 兽人角色：写了物种结构、只属于他的特征、手的结构和服装材质吗？体型交给参考图了吗？光源写成画外哪一侧了吗？背景人物写了种族吗？
- 风格写成了看得见的特征（媒介、线条、上色、光影、配色），没写画师、导演、工作室或作品名？

## 核心技巧（附原因）

**1. 先定用途和画布，再写主体。** 用途决定精致度和版式语言，广告、UI、随手拍完全不同。版式要先于细节写，否则模型会把“细节预算”花在主体上，版式随意发挥。

**2. 具体名词胜过形容词。** “深夜便利店”不如“冷柜上的促销贴纸、湿漉漉的门口地垫、玻璃上的霓虹反光、收银台旁关东煮的热气”。经验值：场景 5–12 个具体名词 + 2–4 条材质/光线约束。材质、光线、色板是三个独立的旋钮，分开写，别用“高级感”一词带过。

**3. 文字渲染是 GPT Image 的强项，也最需要规范。**
- 所有要出现的文字放进引号，逐字给出；写清位置、字体气质、颜色、字号层级和出现次数（如“只出现一次”）。
- 再加一句“画面上的文字只有以上这些，每段只出现一次”。
- 品牌名、生僻词、易错的英文可以逐字母拼写（如 B-L-O-O-M）；中文写明“简体中文”，要求笔画清晰、每个字与原文一致。日文写明“日文（日本汉字字形和假名）”，逐字给出原文。
- 数字、日期、价格按原文的写法照抄，并注明“数字用阿拉伯数字”，否则“8折”可能变成“八折”。
- 点名容易冒出多余文字的表面：包装、杯子、招牌、黑板、桌布、屏幕，写“这些表面保持素面”。门店类画面常会冒出 “BAKERY”“OPEN”“COFFEE” 这类英文装饰字；还冒出来时，用“只改这一处”的编辑去掉。
- 文字有主次时，按重要性分层级：最大的是主题或店名，其次是卖点或优惠，再次是时间地点，行动号召可有可无。用户只给了几句话，就不要硬凑副标题或行动号召。
- 小字和密集信息（信息图、幻灯片、包装背面）用 medium 或 high 质量。长段中文仍可能出错：分区块迭代，最后人工校对每个字。

**4. 写实照片：写“这张照片是怎么拍到的”，别堆相机参数。** 写明“真实照片 / photorealistic / 手机随手拍 / 专业摄影”，再给镜头感、光线、时间和拍摄场合。要真实就保留不完美：毛孔、细纹、衣服褶皱、磨损、背景里的日常杂物；写实场景不用“影棚级完美、磨皮、精修”这类措辞〔官方〕。兽人角色写毛发：毛流方向、长短毛分区、光源在画外哪一侧时毛尖透出的轮廓光、湿毛成绺、胡须清晰〔推论〕。相机参数只是外观提示，不是物理模拟；只选一个主导的拍摄框架，参数一多就互相打架。

**5. 人物：写景别、视线和互动。** 例如“全身入镜，低头看手里的书而不是看镜头”。

**6. 约束写成正向的“只有……”“保持……”。** 排除项先改写成正向：“画面上的文字只有以下三段”“全图只有凯尔一个角色”“手是犬爪手，四根手指加一根拇指，结构清晰稳定”。只在正向写法压不住某个默认错误时，才补 1–2 条排除句，并在回复里标明（文字密集型的图例外，见第 3 步）。

**7. 编辑 = 一处改变 + 一张保留清单。** 句式：“只把___改成___，其余全部保持原样：人物身份/表情/姿势、构图、机位、光线、背景、已有文字。”每一轮都重写保留清单，因为多轮编辑会累积漂移；一轮只改一件事。需要像素级不变的区域，就把改好的局部合成回原图，提示词做不到像素锁定。

**8. 多参考图：编号 + 角色 + 组合方式。** “图1：产品照片（保留外形和标签）；图2：风格参考（只取配色和笔触）；图3：场景。”再说明怎么组合；合成时要求光照方向、透视、比例、接触阴影一致，避免贴图感。

**9. 一致性：先做锚点，再复用。** 先生成一张信息完整的角色或产品锚点图。纯白背景的多视角设定图最稳，因为带风格的背景会把光线带进后面的图。之后每张都附上锚点图，并在提示词里复述关键特征，只描述新场景。

兽人角色（这位用户的主角）：先写一张固定的“身份卡”，每张图原样复制。物种写成看得见的结构（例如狼：完整的狼头和长吻部，全身覆毛，直立双足），再写毛色分区、眼睛、手（犬科角色写“犬爪手，四指加一根拇指”，其他物种以参考图为准）、一个只属于他的特征，服装逐件写材质。体型交给参考图，不写体型形容词；光写成“光源在画外左侧”〔用户记录；物种结构的写法是推论〕。这位用户的设定图版式固定：同一张图里放正面全身、背面全身和头部特写，三个视图的身高和头身比与原立绘一致〔用户记录〕。喂给 Seedance 前裁成单视图（头部一张、全身正面一张），去掉图上的名字和标注，宽高比在 0.4–2.5 之间，分辨率不超过视频的输出分辨率〔官方〕。完整写法见 `references/kemono-character-sheets.md`。

**10. 迭代：一次只改一个变量。** 先出干净的基础版，再看图指出具体哪里不对（哪个字、哪块区域、哪个关系），然后单点修改（“灯光更暖一些”“恢复原来的背景”）。分清失败原因：小字糊、细节不够 → 提高质量档；内容或构图错 → 改提示词。“和之前一样的风格”这类指代会漂移，关键约束每轮都重写。

## 模型与参数速查（截至 2026-10，以 OpenAI 官方文档为准）

| 模型 | API ID | 适用 |
|---|---|---|
| GPT Image 2.5 Flare | `gpt-image-2.5-flare` | 速度优先：日常出图、快速试方向；质量与 GPT Image 2 相当 |
| GPT Image 2.5 Sunburst | `gpt-image-2.5-sunburst` | 质量优先：精细编辑、复杂版式、主体保持 |
| GPT Image 2 | `gpt-image-2` | 兼容已有工作流（2026-04 发布，生成过程开始引入推理） |
| gpt-image-1.5 / 1 / 1-mini | — | 旧版，只用于迁移或省钱的批量草稿 |

官方的选择策略：复杂任务先用 Sunburst 跑通，再用同一提示词试 Flare，质量守得住再切换；原有 GPT Image 2 流程已经够用，就直接试 Flare 换速度。API 里没有叫 `gpt-image-2.5` 的通用 ID：用户只说“GPT 2.5”时，问一句要 Flare 还是 Sunburst，或者按需求替他选并说明理由。

- **quality**：`low / medium / high`，2.5 另有 `xhigh / max`，默认 `auto`。按需逐级提高，不是越高越好（max 会慢很多）。比较模型时手动固定质量档，不要用 auto。
- **size**：宽高都是 16 的倍数，长边 ≤ 3840，长短边比 ≤ 3:1，总像素在 655,360 到 8,294,400 之间；超过 2560×1440 属于实验性。常用：1024×1024（1:1）、1024×1536（2:3）、1536×1024（3:2）、1536×2048（3:4）、2048×1152（16:9）、1152×2048（9:16）、2048×2048、3840×2160（4K，实验性）。21:9 可用 2688×1152。提示词里写“4K”不会改变实际分辨率。
- **background**：透明底用 `transparent` + png/webp（jpeg 不支持）。不要在提示词里要“棋盘格背景”，那样会画出一个假的棋盘格。
- **input_fidelity**：`gpt-image-2` 不要传，它始终以高保真处理输入图。
- **n**：一次出多个变体，适合 Logo 和构图探索。
- **ChatGPT 网页/App**：没有参数面板时，把画幅写进提示词（如“横版 16:9”）。复杂版式、信息图可以开思考（Thinking）模式，让模型先规划布局。2.5 版的 ChatGPT 还有草图（Sketch）转图、模板、在图上圈选评论做局部修改等功能；做局部修改时优先用圈选。ChatGPT 网页有时会把模型降成 gpt-5-4，结果明显变差时，新开对话重跑〔用户记录〕。具体以界面为准。

## 边界

- 真人肖像、名人、他人作品的改编：提醒用户需要有使用权，平台审核也可能拦截；默认生成原创人物和原创品牌。
- 风格不写画师、导演、工作室或作品名，拆成看得见的特征，例如“厚涂数字绘画，明显的方向性笔触，暖色轮廓光，低饱和背景”。
- 只做原创角色，写明“成年男性”；服装写具体的剪裁和材质。光上身的角色偶尔会被审核拦下，重跑一次就行〔用户记录〕。
- 图上的数据、日期、价格、医学或科学内容：只用用户提供或已核实的信息，不要编造；生成后要校对。
- 其他生图模型（Midjourney、即梦图片、Nano Banana 等）也可以借用“结构 + 文字加引号 + 约束”这套写法，但参数部分不适用。
