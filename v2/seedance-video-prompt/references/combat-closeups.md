# 打戏、特写与运镜（兽人角色 · Seedance 2.5）

## 什么时候读这份文件

- 片子里有对峙、出招、格挡、追击或武器碰撞。
- 想用环绕、急推、甩镜、FPV、变速、冲击帧、速度线、拖影这类有冲击力的手法。
- 要拍眼睛、爪子、握剑柄的手、脚踩木板、耳朵、尾巴、伤疤这类特写，或者要移焦、低机位。
- 打戏生成出来方向乱、武器变形、角色四肢着地，或者被审核拦下。

文戏、对白和角色一致性的通用写法见 SKILL.md，这份只管打戏和特写。示例用的是用户自己的角色，档案里没有的细节一律写成“以@图片N为准”；示例情节只为演示写法。

标注：〔官方〕指火山方舟、小云雀、即梦国际版的官方文档和官方 sd25-pe skill；〔多来源〕指两个以上非官方来源说法一致；〔单一来源〕指只有一个来源，含用户自己的实测；〔推论〕指由资料推出、还没实测。兽人专属的写法大多是推论，正式出片前先用 480P 或样片模式单独试最难的那一段。

## 1. 三条总原则

1. **一段只放一个攻防回合，并写清“结束时”。** 时间段是事件预算，不是帧级剪辑点；一段塞太多会过度剪切或漏掉剧情〔官方〕。
2. **一段只用一个主运镜。** 同时要求推拉摇移会让画面不稳〔官方〕；想要运镜多，就在段与段之间硬切换成另一种〔多来源〕。
3. **效果写成画面里发生的事。** 冲击帧、速度线、拖影都是作画术语，官方文档里查不到“冲击帧”“速度线”〔推论：本次检索未见〕，所以要写清看到什么、持续多久、出现几次。

## 2. 一次交手怎么写清楚

每个回合写五件事。社区 Seedance 2.5 skill、日文打戏指南和小云雀官方女骑士案例都这样拆〔多来源〕；“开始时 / 主要事件 / 结束时”的结构来自官方 sd25-pe〔官方〕。

| 要素 | 写什么 | 例句 |
|---|---|---|
| 发起者 | 谁先出手，谁防守 | 肯尼V先出手，瓦胡德防守 |
| 起点与距离 | 两人各在哪、相距多远、重心在哪只脚 | 两人相距约五步，肯尼V的重心压在后脚 |
| 路径 | 从哪到哪、用哪只手、什么轨迹 | 肯尼V从右向左冲出三步，右手的飞刀沿水平直线刺向瓦胡德的肩头 |
| 接触点 | 落在武器、护甲还是格挡的手臂上 | 刀尖撞在长剑剑身中段 |
| 结果 | 写成“结束时”：距离、武器在谁手里、重心、左右位置 | 结束时：肯尼V被震退一步，飞刀仍在他右手，两人相距约三步 |

- 一段 2–4 秒放一个回合〔推论〕。要连击时，一段最多写三个编号节拍“第一击 / 第二击 / 第三击”，三击动作各不相同〔推论，依据小云雀官方女骑士案例〕。
- 连击别用时间戳控制频次（例如“一秒出三拳”），改写成编号节拍〔官方〕。
- 动作整体概括写，只给最有记忆点的一两下写细节，同一个动作只写一次〔官方〕。

| 反例（只用来对照） | 正向改写（可粘贴） |
|---|---|
| 肯尼V旋转跳起连踢三脚，瓦胡德被打得满脸是血。 | 肯尼V借转身的惯性做一次后旋踢，脚背扫向瓦胡德的银肩甲；瓦胡德被震退半步，脚下的石板扬起一点尘土；肯尼V落地后双脚前后分开站稳，上身挺直，飞刀仍在右手。 |

## 3. 节奏与打击感

日式作画的打斗节奏是“停—爆—停”（タメ・ツメ，缓急）：出招前定住蓄力，用很少的几个姿势瞬间爆发，命中后再定住收势〔多来源〕。看得清的电影打戏也是“停顿、一串攻防、再停顿”〔多来源〕。下面每条写法都可以直接粘进对应的镜头。

| 手法 | 可粘贴写法 | 注意 |
|---|---|---|
| 蓄力→爆发 | 出招前两人定住约1秒：重心压在后脚，肩背和颈毛绷紧，只有毛尖和衣摆在风里轻动；下一瞬间爆发冲出，只看得到起手和收招两个姿势；收招后再定住半秒 | “约1秒”“半秒”是软目标，2.5 只认整数秒时间戳〔官方〕 |
| 冲击帧·动画 | 命中的一瞬间画面闪过一帧黑白反相的画面，随后立刻恢复原来的色彩，全片只闪这一次 | 作画术语叫ショックコマ〔多来源〕；日本广播指南要求闪烁和高对比反转原则上每秒不超过 3 次〔单一来源·原始文件〕，模型自己也会闪，所以写明只闪一次 |
| 冲击帧·手绘墨线 | 接触的一瞬间画面变成一帧只有黑色墨线和白纸底色的画面，随后立刻恢复淡彩，全片只闪这一次 | 把单色冲击帧换成《量身》的画材〔推论〕 |
| 冲击帧·写实 | 命中的一瞬间画面停顿约半秒，镜头随冲击震动一次后稳定 | 小云雀机甲案例：“命中点极快，随后半秒停顿”“静止后轻微震动”〔官方〕 |
| 定格 | 剑刃相交的一瞬间画面定格1秒，随后恢复 | 官方支持“画面定格1秒”这类相对时间〔官方〕 |
| 速度线 | 动画：这一击期间背景变成沿冲刺方向的白色速度线，收招时恢复原来的背景。手绘：武器后面拖出几道细墨线速度线。写实：背景沿运动方向拉出动态模糊 | 动画写法〔多来源〕；写实画风用动态模糊代替〔推论〕 |
| 拖影（オバケ / smear） | 挥出的手臂和剑刃拉出一道弯曲的残影拖尾，脸和眼睛始终清晰稳定 | 拖影是作画里激发运动错觉的变形画〔多来源〕；有第三方指南提醒拖影会连带让脸变形，所以只给手臂和武器〔单一来源〕 |
| 变速 / 慢动作 | 只有这一击放慢：从剑刃碰到飞刀开始明显放慢约1秒，火星悬在空中，随后骤然加速回到实时速度；其余时间都是实时速度 | 全片只给 1–2 个决定胜负的接触〔多来源〕；写清从哪开始放慢、在哪恢复、停在什么画面〔官方〕 |
| 切在动作上 | 在瓦胡德挡开飞刀的动作中途硬切到近景，下一个镜头从同一个挡剑动作的后半段接上 | 剪辑点写成动作事件，落在运动中，而不是静止姿势上〔多来源〕；精确到帧的剪辑点留给后期〔官方：时间段是预算〕 |
| 命中震动 | 命中时镜头随冲击震动一次，随后立刻稳定 | 小云雀机甲案例〔官方〕 |

- 同一击从两三个角度重放（重复剪辑）是日式动画的常见手法〔多来源〕，但官方建议同一个动作只写一次〔官方〕；要这个效果，生成后在剪辑软件里复制。
- 关键一击前可以让声音收住，但要写清哪一秒恢复，例如“第20秒风声收住，只剩两人的呼吸声；第21秒 <金属撞击声> 落下，风声恢复并持续到最后一秒”。用静默衬托冲击是动画和电影的惯例〔多来源〕；用户实测，环境声没写到最后一秒时后半段可能静音〔单一来源·用户实测〕。

## 4. 运镜短语库

写法：运镜名 + 作用主体 + 起点 + 方向 + 终点〔官方〕。一段只用一种；手持本身就算一种，别再叠环绕或急推〔多来源〕。示例里瓦胡德在画面左侧、肯尼V在右侧。

| 运镜 | 用在哪 | 可粘贴写法 | 依据 |
|---|---|---|---|
| 环绕 | 决胜交击、亮相 | 以两人之间的交击点为圆心，中景向右缓慢环绕约60度后停住，全程是一个连续镜头，停在两人连线原来的一侧 | 写清圆心、方向、角度〔官方〕；从侧面起转、弧度在 90 度以内就留在连线同一侧〔推论〕 |
| 短弧环绕 | 对峙、台词前后 | 近景，镜头绕凯尔向左缓慢环绕约15度后停稳 | 用户常用 10–15° 短弧〔单一来源·用户习惯〕 |
| 急推 | 命中瞬间，推向交击点或眼睛 | 接触的一瞬间镜头急速变焦推近，画面极快地由中景收紧到交击点特写后停住 | 〔多来源〕；冷门术语展开成画面变化〔官方〕 |
| 甩镜 | 回合之间，转向反击者或反应 | 镜头从瓦胡德快速向右甩到肯尼V，带横向动态模糊，甩过去后继续向右运动、速度相近 | 甩完延续同一方向和速度〔官方：小云雀甩镜转场〕 |
| FPV | 开场交代空间 | FPV视角从桅杆顶端俯冲，贴着甲板穿过两排缆绳之间，减速停在两人侧方 | 写路径、速度、转向〔官方〕 |
| 手持 | 近身缠斗 | 手持跟拍瓦胡德，轻微晃动，主体清晰；命中时随冲击震动一次后迅速稳定 | 小云雀女骑士案例“轻微手持晃动但主体清晰”〔官方〕 |
| 子弹时间 | 全片最多一次 | 剑刃与飞刀相交的一瞬间动作几乎冻结，火星和落叶悬停在空中，镜头绕交击点向右环绕约60度，随后恢复实时速度 | 写冻结哪个动作、环绕方向〔官方〕 |
| 侧面跟拍 | 追击、冲刺 | 镜头与肯尼V平行向左横移，他始终在画面中央 | 用户常用〔单一来源·用户习惯〕；主体居中，快切也看得清〔多来源〕 |
| 低机位广角仰拍 | 对峙、强势一方登场 | 低机位广角仰拍，伸向镜头的剑尖在前景被放大，身后的屋檐向上倾斜 | 仰拍显得强大，动作戏用广角夸张前景〔多来源〕 |

## 5. 屏幕方向与轴线

- 固定写法，每段重复一次：“A始终在画面左侧、面朝右；B始终在画面右侧、面朝左；摄影机始终在两人连线靠<固定物>的一侧”〔多来源〕。用门、石井、船舷这类不会动的东西做锚点，比只写左右更稳〔官方〕。
- 环绕或子弹时间结束后，让镜头停回原来一侧；转过了头，就切一个全景重新交代方位〔推论〕。
- 两人要交换位置，写出走位路线，例如“肯尼V从瓦胡德身前向左跑过，停在画面左侧”。长得像的角色不写走位就会互换〔单一来源·用户实测〕。
- 追击全片保持同一个运动方向，例如始终从画面左侧跑向右侧〔多来源〕。
- 日式动画的对峙镜头常把处于下风的一方放在左侧面朝右，强敌在右侧面朝左〔单一来源〕。
- 用户文戏常用“同侧正反打不越轴”，打戏的正反打同样让摄影机全程在连线同一侧〔单一来源·用户习惯〕。
- 第一人称（海崖主线）：镜头就是“我”的眼睛，方位按“在我正前方 / 我的左手边”写；有人挡到我和敌人之间时，写清他从哪一侧进入画面〔推论〕。

## 6. 武器、服装和肢体的稳定

| 风险 | 正向写法（可粘贴） | 依据 |
|---|---|---|
| 武器变形、变长 | 全片只有这一把长剑，剑身笔直坚硬，长度始终一致，一直握在瓦胡德手里 | 道具写数量和归属〔官方〕；写刚性和长度〔单一来源〕 |
| 武器换手、换人 | 长剑只属于瓦胡德；飞刀只属于肯尼V，样子和数量以@图片3为准 | 〔官方〕 |
| 招式太杂 | 瓦胡德只用劈砍和格挡，肯尼V只用直刺和投掷 | 一种攻击语法，模型会反复执行同一套动作〔单一来源〕 |
| 战损前后对不上 | 灰蓝披风下摆被划开的那道口子从出现起一直保留到结尾 | 战损只累积、不复原〔单一来源〕 |
| 快动作时肢体扭曲 | 每一拍只做一个简单动作，两人之间留出一臂以上的距离；动作之间写惯性衔接：“借着转身的惯性顺势抬剑” | 补过渡衔接〔官方〕；拉开距离、减少同时接触，旋转跳踢和急转向最容易变形〔多来源〕 |
| 兽手结构乱 | 手是带爪的兽手，手指数和爪数以参考图为准，结构清晰稳定；握剑时爪尖收起贴着剑柄 | 〔推论〕 |
| 尾巴和长毛像固体 | 转身时尾巴和颈毛带着惯性甩出，随后回弹；跃起时尾巴伸直保持平衡 | 〔推论〕 |
| 低姿势变成四肢着地 | 双脚前后分开站稳，膝盖弯曲，上身挺直；倒地写“单膝跪地，上身挺直” | 写“半蹲”会四肢着地〔单一来源·用户实测〕 |
| 下水变成真动物 | 席尔在水中也保持直立的兽人身形，双手握着海叉 | 贡纳尔下水变成了真虎鲸〔单一来源·用户实测〕 |
| 一个角色变成两个 | 同一画面中每个角色只有一个 | 防分身〔官方〕（官方原句是负向写法，这里改成正向） |
| 分条生成后换装 | 每条视频都重新附上每个角色自己的参考图；上一条的末帧只用来定站位 | 〔单一来源·用户实测〕 |

## 7. 合规的舞台化打戏

即梦大陆版没有公开的暴力审核细则〔推论：本次检索未见〕，审核结果也有随机性〔多来源〕。下面的写法让合规的虚构打戏少被误判，不是用来包装血腥内容。

| 想表达 | 正向写法（可粘贴） | 依据 |
|---|---|---|
| 开场定性 | 原创成年兽人角色之间的舞台化武打，动作干净利落，像演武一样 | 〔多来源〕 |
| 命中 | 攻击落在剑身、护甲或格挡的手臂上，力道表现为火星、尘土、金属划痕和布料被划开的口子 | 小云雀女骑士案例“沉重金属碰撞，火星四溅”〔官方〕；〔多来源〕 |
| 受伤、落败 | 失去平衡后退两步，单膝跪地，上身挺直；武器脱手落在石板上 | 〔多来源〕 |
| 全身状态 | 两人的毛发、皮肤和衣服始终完整干净 | 假装受伤或险些受伤时保持皮肤、服装和道具完整〔官方：sd25-pe〕 |
| 愤怒、压迫感 | 双耳后压贴头，鼻梁起皱露出犬齿，颈毛竖起，尾巴绷直 | 情绪写成身体细节〔官方〕；耳尾通道〔推论〕；“嗜血、撕咬、凶猛”这类词容易被拦〔多来源·社区〕 |
| 眼神 | 眼睛是自然的兽瞳，只有正常的湿润高光 | 强烈情绪词可能让眼睛发光〔官方〕 |
| 武器种类 | 冷兵器：剑、飞刀、海叉 | 即梦国际版规范限制枪械、弹药和爆炸物，冷兵器不在其列〔官方·国际版〕 |

被驳回时，先删掉可能敏感的措辞再试；版权类驳回多半是某张全身参考图触发的，剔除那一张重试〔单一来源·用户实测〕；同一条提示词多试几次也可能通过〔多来源·社区〕。

## 8. 特写工具箱

- **先因后果**：先用中景让观众看清触发原因（剑刃逼近、对手开口），再切或推到特写〔官方〕。
- **少而准**：每个回合最多插一个细节特写〔单一来源〕；全片最紧的景别留给转折点，特写停留时间比全景短〔多来源〕。
- **长吻部用四分之三侧脸**：正脸会把吻部压扁、挡住眼睛〔多来源〕。
- **大鬃毛的角色少用极低机位仰拍**（例如白鬃的波波）：从低角度看，鬃毛轮廓会变怪〔单一来源〕。
- **手和爪的特写动作要少**：视频模型普遍不擅长手部特写〔单一来源〕。
- **难拍的机位先出空镜**：贴地低机位、极近大特写，先出一张该机位的空镜作参考图〔单一来源·用户实测〕。
- **说话的特写**：胸口以上，台词期间镜头稳定，说完拉回中景〔单一来源·用户习惯〕；吻部完整露在画面里〔推论〕。近景用 50–65mm 时，同时写看得见的结果“人物立体，背景适度虚化”，焦距只能补充、代替不了可见结果〔官方〕。

| 部位 | 可粘贴写法 | 机位与焦点 | 插在哪里 |
|---|---|---|---|

## 9. 30 秒打戏节奏表

A 是先出手的一方，B 是防守方。每段只有一个回合、一个主运镜，结尾写“结束时”。

| 时间 | 段落 | 镜头（景别 · 机位 · 唯一主运镜） | 动作与声音 | 结束时 |
|---|---|---|---|---|
| 0–3秒 | 建立 | 全景，低机位，固定或缓慢横移 | 两人对峙，交代左右站位、轴线和锚点；只有风吹毛发和衣摆在动；环境声从第0秒开始 | 两人相距约五步，各自握好武器 |
| 3–6秒 | 第一回合（一攻一防） | 中景侧面，固定 | A 先定住约1秒，再爆发冲出，攻击落在 B 的武器上；接触瞬间闪一次（全片唯一一次） | 两人被震开，相距约三步 |
| 6–9秒 | 反击 | 切在格挡反弹的动作中途；近景，手持轻晃，主体清晰 | B 借惯性反打一次，武器后面拖出速度线或动态模糊 | 两人重新面对面，武器指向对方 |
| 9–11秒 | 反应 | 先用中景看清原因，再急推到眼部大特写 | 瞳孔收缩一下，双耳后压，胡须轻颤 | 特写停住，眼睛清晰 |
| 11–14秒 | 重置拍（间） | 中景，固定 | 拉开距离、重新摆架势、喘息；需要台词就放这里，只有一人说一句短台词，另一人闭着嘴静静听 | 两人回到起始距离 |
| 14–18秒 | 第二回合（三拍） | 中景侧面跟拍 | 第一击直刺、第二击横扫、第三击下劈，三击都落在武器或护甲上 | 一方后退半步，重心落在后脚 |
| 18–21秒 | 决胜一击 | 固定机位，全片唯一一次回弹变速 | 接触瞬间放慢约1秒，火星和落叶悬空，随后加速回到实时速度 | 武器被弹开 |
| 21–25秒 | 结果 | 硬切；中景向右环绕约60度后停在原来一侧 | 武器脱手；一方单膝跪地，上身挺直 | 两人回到原来的左右位置 |
| 25–30秒 | 收束 | 全景，缓慢后拉并升高 | 垂下武器；可以放最后一句台词；环境声持续到最后一秒 | 画面稳定停留 |

- 为什么是 9 段：官方 30 秒示例是 9 个镜头（3/3/4/4/4/4/3/3/2 秒）〔官方〕；日式 TV 动画平均每个镜头约 3–4 秒，30 秒切 8–10 个镜头，密度相当〔推论，依据多来源的镜头数统计〕；开头慢、高潮段镜头最短、结尾回到更长更平静的镜头〔单一来源〕。本表的时间分配是〔推论〕，综合了小云雀官方女骑士案例（2–3 秒一段）和社区打戏模板。
- 求稳就合并成 6 段：建立 / 第一回合加反击 / 反应加重置拍 / 第二回合 / 决胜加结果 / 收束。小云雀一般建议 30 秒拆 4–6 段，否则后半段容易跑偏〔官方〕；每多一段就多一次出错的机会〔推论〕。
- 要配乐就用 () 写曲风和起止，例如“(低沉的太鼓从第18秒进入，第25秒停止)”〔官方：音乐用 ()〕；默认写“声音只有环境声、动作声和台词”。
- 台词放在重置拍和收束段：激烈动作中说长台词，口型容易乱〔推论，依据社区经验〕。
- 一镜到底的打戏：压到 3–4 段，每段开头写“镜头不停，继续……”，并写出镜头的移动路线；用户电脑上的实测在两段交界处被硬切过一次〔单一来源·本地实测〕。武戏也可以按官方建议分段生成、后期再剪〔官方〕。
- 最密的第 4–7 段先用 480P 或样片模式单独试〔推论〕。

| 攻击没有来源、方向乱 | 按第 2 节五要素重写这一回合 |
| 中段动作糊成一团 | 一段只留一个回合；两人拉开一臂以上距离；这一拍改成更宽、更短的镜头〔多来源〕 |
| 剑变弯、变长、跑到别人手里 | 武器单独写一行：唯一一把、属于谁、笔直坚硬、长度一致，并附参考图 |
| 角色四肢着地 | 把“半蹲 / 伏低”改成“单膝跪地，上身挺直”或“双脚前后分开站稳，上身挺直” |
| 两人左右互换 | 每段重复左右站位和锚点；环绕停回原侧；交换位置写走位 |
| 连续镜头在两段交界被切开 | 每段开头写“镜头不停，继续……”，写出镜头路线，减到 3–4 段 |
| 画面闪个不停 | 冲击帧写“全片只闪这一次”，一条片子最多 1–2 处 |
| 慢动作到处都是 | 点名唯一一次变速，其余写“实时速度” |
| 眼睛发光 | 删掉“杀气、狂暴、兽性觉醒”这类词，写“自然的兽瞳，正常的湿润高光”〔官方〕 |
| 被审核拦下 | 用第 7 节的正向写法；剔除触发的全身参考图后重试 |
| 海上、雨中出现冒泡声或回声 | 声音段写清想要的声音（风、缆绳、木板吱呀），少写浪、水花和回音〔官方：水、波浪、回音相关描述可能带来冒泡或回音噪声〕 |
| 台词口型乱 | 台词挪到重置拍或收束段，近景固定机位，一段只让一个人开口 |
