# 镜头与声音术语表

## 什么时候读这份文件

写景别、机位、运镜、转场、光线和声音时查词；给说日语的角色写台词标签时，查声线、语体、一人称和读音（第 11 节）。这是一份速查表，展开的写法在别处：

- 打戏运镜、冲击感和特写：`combat-closeups.md`
- 兽人日语对白的完整流程（拍数换算、吻部口型、正反打、防字幕、音色参考）：`kemono-jp-drama.md`

## 1. 写法原则

- 通用术语直接写；冷门术语写成“术语 + 作用主体 + 画面变化 + 前后景关系 + 方向或速度”；热门运镜写成“运镜名 + 作用主体 + 起始位置 + 运动方向 + 到达位置”〔官方 sd25-pe〕。
- 一段只用一个主要运镜，写清方向和速度〔官方 2.0〕；主体运动和相机运动分开写，如“他向画面右侧走，镜头向右平移跟随”〔单一来源〕。想要运镜多，就在段与段之间换〔多来源〕。
- 运镜有动机：人物起身时镜头随之升高，人物停步时镜头同时停稳〔多来源〕。
- 下面的“写法示例”都是正向描述，可以直接粘贴〔你的记录：负向写法损伤细节〕。

## 2. 景别

官方词表：大全景、全景、中景、近景、特写〔官方〕。

| 景别 | 画面范围 | 常见用途 |
|---|---|---|
| 大远景 / 大全景 | 人很小，以环境为主 | 开场交代地点，结尾留白 |
| 远景 / 全景 | 人物全身 + 较多环境 | 交代人物和空间的关系；打戏先用它交代站位〔多来源〕 |
| 中景 | 膝盖或腰部以上 | 动作、对话 |
| 中近景 | 胸部以上 | 对话、表情加手势 |
| 近景 | 肩部以上 | 情绪；说台词的人给胸口以上的近景，台词期间镜头稳定，说完拉回中景〔你的记录〕 |
| 特写 | 脸或单个物体 | 情绪爆点、产品细节；全片最紧的特写留给转折那一刻〔多来源〕 |
| 大特写 / 微距 | 眼睛、指尖、材质纹理 | 质感、悬念；兽人可以拍耳尖、鼻头、胡须、尾尖〔推论〕 |

## 3. 机位和角度

官方词表里的机位：低角度、俯视、第一人称、斜侧面、过肩〔官方〕。常用的还有平视、仰拍（低机位仰视）、顶拍（正上方俯视）、荷兰角（倾斜构图）、手机自拍视角、车载或行车记录仪视角、监控视角。

| 写法 | 示例（可直接粘贴） | 依据 |
|---|---|---|
| 机位高度 | 平视，机位在胸口高度，固定镜头 | 你的记录：每镜写机位高度 |
| 低机位特写 | 镜头贴着木地板，拍靴子一步步踏下 | 你的记录 |
| 过肩 | 前景是听者虚化的肩膀和耳朵，越过它拍说话者的四分之三侧脸 | 官方分镜示例；兽人写法见 `kemono-jp-drama.md` 3.1 |
| 轴线 | 镜头始终在两人连线靠窗的一侧；A 始终看向画面右侧，B 始终看向画面左侧 | 官方（小云雀示例、sd25-pe：用门、桌、窗这类固定物体锚定） |
| 第一人称 | 镜头就是“我”的眼睛，高度是我的视线高度；对我说话的人直视镜头 | 官方词表有“第一人称”；逐条改写是推论，见 `shot-grammar.md` 6.1 |

## 4. 运镜

| 运镜 | 写法示例（可直接粘贴） | 注意 |
|---|---|---|
| 推 | 镜头缓慢向前推近她的脸，推到近景后停稳 | 顿悟、下决心时从中近景极慢推到特写〔多来源〕 |
| 拉 | 镜头向后拉远，露出整个房间 | |
| 摇（水平） | 镜头在原地从左向右摇，扫过整条街 | |
| 俯仰（垂直摇） | 镜头从人物的鞋向上仰起，直到天空 | 机身原地转动；要机位升高写“升” |
| 移（横移） | 镜头与人物平行向右横移 | 前景、人物、远景以不同速度平移，就有纸片层叠的视差〔多来源〕 |
| 跟 | 镜头在人物身后一米处跟随 | 侧面跟拍：镜头和他平行向右移动〔你的记录〕 |
| 环绕 | 镜头以产品为圆心，顺时针匀速环绕半圈 | 写圆心、方向和速度〔官方：小云雀 360° 示例〕 |
| 短弧环绕 | 镜头绕两人向右短弧环绕约15度，停在原来这一侧 | 你常用 10–15°〔你的记录〕；超过约 90° 两人会左右互换〔推论〕 |
| 升 / 降 | 镜头从地面缓缓升到屋顶的高度 | |
| 慢慢露出 | 镜头从脚边慢慢向上仰，依次露出腰带、肩甲和脸 | 写清从下往上的顺序〔你的记录〕 |
| 手持 | 轻微手持晃动，镜头偶尔慢半拍再追上人物 | 写跟谁、晃多大〔官方〕 |
| 固定 | 机位固定，画框稳稳停住，只有人物在动 | 保留呼吸、衣料和毛发的轻微动态〔单一来源〕 |
| 急推（变焦） | 急速变焦推近，画面由中景极快收紧到窗口特写后停住 | crash zoom 按冷门术语展开〔推论，依官方规则〕 |

## 5. 热门运镜

官方列出可以直接写名字的：一镜到底、希区柯克变焦、航拍、FPV、子弹时间、手持、回弹变速〔官方〕。名字后面补上参数：

- **一镜到底**：全程不切镜，用镜头路线串起多个空间。按时间段写，不写“镜头1 / 镜头2”〔单一来源〕；每段开头写“镜头不停，继续……”，跨空间时写出穿越路线，例如“镜头不停，继续跟着他跨过门槛进入店内，从柜台左侧绕到他身前”。本地实测：早餐铺示例在两段交界的第 7.38 秒被硬切，从门外直接跳到店内〔本地实测〕。连续性要求高时压到 3 段，或拆成两条用首尾帧、延长接上；空间连不起来时，别同时要求“一镜到底”和“瞬间换场景”。完整示例见 `templates-30s.md` 第 1 节。
- **希区柯克变焦（滑动变焦）**：镜头向前推的同时焦距拉远，人物在画面里的大小始终一致，背景向后拉伸，用来表现震惊或眩晕；写清主体保持多大、背景怎样变〔官方〕。
- **航拍**：写清高度变化和方向，如“低空掠过江面后缓慢升高”。
- **FPV**：写路径、速度和转向，如“高速贴着屋脊飞行，从两根烟囱之间穿过后向右转”〔官方〕。
- **子弹时间**：写凝固的瞬间和环绕方向，如“水花悬停在空中，镜头绕主体逆时针转半圈”〔官方〕。
- **回弹变速**：写在哪个节点慢下来、在哪里回到实时速度、最后停在什么画面〔官方〕；全片只给 1–2 个关键瞬间〔多来源〕。
- **移焦（焦点转移）**：官方写法“移焦，画面焦点发生平滑转变，原本在前景清晰的树木变模糊，背景中的人物由模糊逐渐变得清晰”〔官方〕；再写清第几秒发生、焦点从谁转到谁。
- **甩镜**：官方写法“第5秒镜头快速向左横移；前景书架完成整屏遮挡时切换到下一场景，切换后镜头继续保持向左运动和相近速度”〔官方：小云雀〕。

## 6. 转场

前景遮挡（某个物体从左侧入画遮住镜头，移开后已是新场景）、甩镜、人物旋转、物体变形（咖啡杯里的漩涡变成星空）、推进穿越（镜头推进穿过窗户进入下一个场景）、焦点虚化转场、匹配剪辑（用相同的形状或动作衔接）、硬切。写清在第几秒发生、怎么发生、到达什么画面。

声音也能做转场：下一场的声音提前约一秒响起（J 剪辑），或上一句台词延续到下一个画面（L 剪辑）〔多来源：电影剪辑惯例〕。写法：“第14秒起<电车进站的铃声>先响起，第15秒画面硬切到站台”。模型不一定做得准，先用样片试〔推论〕。

## 7. 镜头参数 → 看得见的结果

焦距、光圈和快门只能补充，画面结果要写出来〔官方 sd25-pe〕。

| 想写的参数 | 更可靠的写法 |
|---|---|
| 24mm 广角 | 空间感强，近处的物体显得大，画面边缘轻微拉伸 |
| 50–65mm（你给说话近景的常用焦段） | 透视接近人眼，人物立体，背景适度虚化〔你的记录〕 |
| 85mm 人像镜头 | 背景被压缩并虚化，人物立体 |
| 长焦 | 人物和身后的人群被压成一层，背景化成柔和的色块〔多来源〕 |
| f/1.4 大光圈 | 背景虚化成柔和的光斑 |
| 高速快门 | 水滴和发丝清晰地凝固在空中 |
| 慢门 | 车灯拉出光轨，人群模糊成流动的影子 |

## 8. 光线

写清楚光从哪里来、照在谁身上、留下什么阴影。方向写成“光源在画外左侧”这样的位置；只写“逆光”，会在头顶出光晕〔你的记录〕。

| 想写的 | 更稳的写法 |
|---|---|
| 逆光 | 光源在画外左后方，人物的耳朵和肩膀边缘有一圈细亮边，脸在柔和的阴影里 |
| 窗光 | 自然光从画面左侧的窗户照进来，照亮半边脸，另一半落在柔和的阴影里 |
| 黄金时刻 | 低角度的暖金色夕阳从画外右侧照来，影子拉得很长 |
| 顶光（压抑） | 光从正上方的吊灯照下，眼窝和下颌下方落进阴影 |
| 底光（不安） | 光从下方的炭火照上来，脸的下半部最亮 |
| 低调光 | 光只来自画面里的油灯和窗外的月光，房间整体偏暗，暗部仍看得清轮廓和毛发纹理〔多来源〕 |
| 体积光 | 光束从画外左上方的高窗斜射进来，穿过空气里的浮尘 |

其他常用：阴天柔光、霓虹混合光、画面里的实际光源（台灯、手机屏幕、烛光、车灯）。全片统一一套色，例如“暗部偏青蓝，灯光和毛色偏暖金”〔多来源〕。

## 9. 声音符号和台词行

### 9.1 官方符号

| 内容 | 符号 | 示例 |
|---|---|---|
| 音乐 | `()` | `(背景播放舒缓的钢琴乐)` |
| 音效 | `<>` | `<远处传来钟声>` |
| 台词 | `{}` | `{……これは命令だ。}` |
| 字幕 | `【】` | `【第一章：启程】` |

依据：Seedance 2.5 教程原文“声音用特殊字符区分：音乐用 ()、音效用 <>、台词用 {}、字幕用 【】”，sd25-pe 的符号表相同〔官方〕。（`sources.md` 记的是“只是惯例”；2.5 教程已经写成规则。）

- 【】在符号表里是字幕，官方示例也拿它做段落标题（【参考素材职责】【事件脚本】）。台词只放 {}；段落标题被画进画面时，改成“画风：”这样的纯文字标题〔官方 + 推论〕。
- 用 <> 标音效时，角色名不加尖括号，写普通名字〔官方 sd25-pe〕。
- 非中文台词在台词前写明语言；多个说话人逐个标注，只在开头统一声明一次不够〔官方〕。

### 9.2 台词行

格式：`角色名（语言，音色，情绪，对谁说）：{原文}`。写在这句话发生的时间段或镜头里，全片每句只写一次；【声音】段只写总句数，不重复原文〔官方 + 你的记录〕。

| 场合 | 写法（日语台词来自你的角色设定） |
|---|---|
| 画内说话 | 凯尔（日语，冷酷大哥式的低沉男声，压低声音但有力，对杰拉德）：{……これは命令だ。}杰拉德闭着嘴静静听。 |
| 画外台词，画面在听者脸上 | 画面是凯尔的近景，他闭着嘴，双耳先往后压了一下。杰拉德（画外，日语，呆板、一本正经的中年男声，郑重，对凯尔）：{承知した。} |
| 对“我”说（第一人称） | 赛伦看着镜头。赛伦（日语，明亮的少年男声，小声，对我）：{……もう一回。} |
| 内心独白 | 凯尔的吻部闭合，视线落在窗外。凯尔（V.O.，日语，冷酷大哥式的低沉男声，自言自语）：{台词原文} |
| 旁白 | 旁白（V.O.，中文，沉稳的男声，平静，对观众）：{台词原文} |
| 其他外语 | 汤姆（英语，温和的青年男声，轻松，对店员）：{Just a coffee, please.}；地区口音只在用户指定时加，例如“自然、口语化的美式英语”〔官方 sd25-pe〕 |

- 同一段只让一个人开口，其他在场的人写“闭着嘴静静听”〔官方 sd25-pe + 你的记录〕。
- 迟疑、打断直接写进台词：「……」「——」〔官方示例〕。
- 情绪写在台词前的括号里；在台词后面复述台词里的词、追加“X 后停顿”这类说明，容易诱发字幕〔官方 FAQ〕。
- 中文意思写在提示词外面；放在 {} 旁边，可能被念出来或变成字幕〔推论〕。

## 10. 环境声、音效、音乐和正向写法

| 类别 | 写法示例 | 注意 |
|---|---|---|
| 环境声 | 0–30秒：<雨点打在铁皮屋顶上>和<远处电车的低鸣>一直持续到最后一秒 | 写到最后一秒，否则后半段可能静音〔你的记录〕 |
| 动作音效 | 第12秒<木门被拉开的吱呀声> | 按物理来源写，和动作写在同一秒；“氛围感音效”换成具体声源 |
| 音乐 | (舒缓的钢琴独奏，约70 BPM，第25秒渐弱结束) | 写曲风、速度和起止秒 |
| 静音设计 | 第16秒起其他声音切断，只剩<心跳声> | |
| 关键台词前的安静 | (低沉的弦乐)从第3秒响起，在第9秒那句台词前一拍停住，留出约1秒只有呼吸声和环境声的安静 | 日式动画常用〔多来源〕 |
| 主观声音 | 被击中的瞬间所有声音变闷，只剩<耳鸣>和<心跳>，两秒后恢复 | 电影常用〔多来源〕 |
| 高潮进音乐 | 最后一句台词说完、镜头停在特写上时，(抒情弦乐淡入) | 电视剧常用〔多来源〕 |
| 层次 | 台词最清楚，环境声只留一两种 | 每 5 秒约 5 层为上限〔单一来源〕 |

提示词里写水、波浪、回音，音频容易冒出气泡声、回声和啸叫〔官方 FAQ〕。雨夜、海边、洞窟戏只写一两种具体声源；“广播的回声”写成“模糊的广播人声”。

### 排除写成正向

| 想排除 | 正向写法 | 依据 |
|---|---|---|
| 背景音乐 | 声音只有环境声、动作声和台词 | 你的记录 |
| 多余的台词 | 全片共两句台词，其余时间所有人闭着嘴 | 官方“闭口聆听”的正向版 |
| 旁白 | 全片的人声只有画面里角色的台词 | 推论 |
| 动物说话 | 乌鸦是普通的鸟，只发出乌鸦的叫声；台词只由阿杰说 | 官方要求写清说话人；正向化是推论 |
| 字幕 | 画面是纯净的影像，文字只出现在场景里原有的招牌上 | 你的记录 |
| 写了“大声” | 压低声音但有力 | 你的记录：“大声”会抬高音高 |
| 唱歌、哼唱 | 用正常说话的语调说 | 单一来源：氛围类提示偶尔让人声变成哼唱 |

正向写法失效时的官方备用（负向写法，只在排障时用）：字幕写“画面不显示字幕”〔官方 sd25-pe〕；背景音乐写“音频只保留角色人声、环境声和动作声”，再把音乐类同义词（音乐、背景音乐、BGM、配乐、器乐、旋律、合成器音效、氛围铺底音）的排除在提示词开头和结尾各写一遍〔官方 FAQ〕。

## 11. 日语声线与语体

### 11.1 声线卡

每个角色一句固定的声线描述，填进台词标签的“音色”位置，每个说话镜头原样复制〔多来源〕。改一个形容词就可能改变声龄和质感〔单一来源〕；只重复声质、不重复口吻时，台词温柔的镜头口吻会被带软〔单一来源〕。官方 2.0 的音色描述示例：“使用@音频1低厚温润带细碎颗粒感中年男声的音色说”〔官方 2.0〕。有音色参考时，声线卡只做补充。你的角色的声线卡见 `kemono-jp-drama.md` 2.2。

### 11.3 语体和一人称：写进台词本身

性格很大一部分靠“怎么说”：一人称、敬语程度和句尾直接写进台词，比只在括号里写“豪爽的语气”更可控；同一角色全片用同一套一人称和句尾〔推论，依据役割語〕。括号里的“古风骑士腔”只做补充，声音段再写“严格按照台词原文生成音频，逐字说完”（官方约束句的正向改写）。

### 11.5 读音、停顿和语速

- 难读的汉字写成假名：飯 → メシ〔你的记录〕。社区实测「焙煎」被读成「ばいこう」，改成平假名后读音对了，语调还是改不动〔单一来源〕。只改真正读错的词，大量改成假名可能打乱整句节奏〔单一来源〕。
- 名字、招式名、自造词：能不念就不念，要念就写片假名〔你的记录 + 多来源〕。
- 数字写成读法：「3人」→「さんにん」〔单一来源〕。
- 语速换算时长按拍（モーラ）算：克制的文戏按每秒 5–6 拍，普通对话不超过每秒 7 拍，每句再加约 1 秒〔推论〕；数拍规则和例表见 `kemono-jp-drama.md` 2.3。
- 某个词反复读错：上传一段只含这个词的读音音频，写“@音频3只参考读音和语调，音色以@音频1为准”；有时连音色也被带走〔单一来源〕。

### 11.6 音色参考的绑定

写“图片1是凯尔，图片1使用音频1音色”；每人两张图时写“图片1、图片2是凯尔，对应音频1”；按角色首次出场的顺序上传和编号〔官方〕。单段 5–10 秒的单人干净人声效果较好〔官方〕；一条最多绑两条声音参考〔你的记录〕。音频只提供音色、口音、语速和情绪，台词内容以文字为准〔官方 sd25-pe〕。规格见 `kemono-jp-drama.md` 2.6。
