## 1. 通用结构

有参考素材：

```text
@图1是[主体]，外观照这张；@视频1的[运镜/动作/动线/站位]照它来，[外观/材质]以@图1为准；@音频1作为[角色]音色。

[主体]在[地点]完成[事件]。[视觉材质与光线]，[镜头策略]。

0—[秒]秒：[画面]。[镜头]。[动作]。[台词与声音]。
[秒]—[秒]秒：[下一段，承接上一段结果]。

[身份、数量、站位、道具、动作、光线和声音连续性约束]。
```

无参考素材时，删去第一段，在总体画面中补足主体的必要视觉定义。

时长、比例和分辨率留在即梦界面，不作为提示词句子。

## 2. 时间轴写法

正确：

```text
0—4秒：镜头贴近桌面缓慢前移，角色甲伸手扶住杯子。
4—9秒：镜头随杯子抬高，角色甲看向右侧的角色乙并说话。
9—15秒：角色乙接过杯子，镜头停在两人的手和杯子上。
```

特点：

- 连续、不重叠、无空隙。
- 段长随内容变化。
- 时间后直接写动作。
- 每段有明确承接关系。

错误：

```text
全片15秒，16:9。
0—5秒【开场】：角色甲做三个复杂动作。
6—10秒【发展】：两人同时跑动、说话、交换道具。
```

## 3. 常规生成模板

```text
[逐项素材映射。]

[一句话概述主体、地点、事件、具体视觉风格和镜头策略。]

0—[A]秒：[建立画面与第一个动作。]
[A]—[B]秒：[承接上段结果，执行第二个动作。]
[B]—[C]秒：[转折或关键交互。]
[C]—[目标时长]秒：[完成动作并停在明确结尾构图。]

[身份、数量、站位、道具、光线、物理和声音约束。]
```

30 秒不固定段数。先列动作节点，再按完成动作需要的时间分配区间。

## 4. 白模模板

### 粗颗粒度

```text
只参考@视频1的[运镜、动作、动线、站位、轨迹、光影或节奏]，人物外观与材质以角色参考图为准。
@视频1中的[位置/颜色/形状]模型对应@图1的[角色甲]；[另一模型]对应@图2的[角色乙]。[音色映射。]

[最终场景、事件、视觉材质、光线与镜头原则。]

0—[A]秒：[最终角色按白模预演完成第一段动作。]
[A]—[B]秒：[动作承接。]
[B]—[目标时长]秒：[结果与结尾。]

[角色各自保持站位、动作顺序、道具归属、物理连续性，全段声音与字幕的正面描述。]
```

### 细颗粒度

```text
将@视频1的完整白模动画渲染成最终成片，严格保持原视频的模型结构、动画、运镜和构图。

0—[A]秒：[场景、材质、色调、灯光、粒子或流体要求。]
[A]—[目标时长]秒：[材质或场景变化及触发点。]

[PBR材质、反射、折射、阴影、光照和渲染一致性。]
```

## 5. 视频延长模板

```text
参考@视频1向后续写。保持原视频最后一帧的角色身份、位置、姿势、运动方向、构图、光线和声音连续。

新增开始后：[角色或镜头从原有状态继续执行的动作]。
随后：[下一动作或自然转场的触发物、方向和承接画面]。
结尾：[明确可见的停止状态或下一次续写锚点]。

原视频内容保持原样；新增部分从末帧的位置和道具直接继续，声音连续到结尾。
```

延长提示词只写新增部分，不重新写原视频完整时间轴。

## 6. 编辑模板

```text
在[红框/箭头/地标点/画面方位]内，把[具体目标]从[A状态]修改为[B状态]，从[生效时间]开始并保持到[结束时间]。

只修改[目标属性]；[人物身份、脸、身体动作、其他服装、道具、背景、构图、镜头、光线、字幕和声音]保持不变。被遮挡区域按原场景透视、纹理与光线自然补全，补全后的区域清晰稳定，边缘干净。
```

## 7. 无缝转场模板

```text
把@视频1与@视频2无缝衔接，两个原视频内容保持不变。

@视频1结尾的[主体/物体/镜头]继续沿[方向]运动，[触发物]逐渐填满画面；遮挡解除后进入@视频2开头。[形状、颜色、运动方向、焦点或声音]在两端保持连续。

只生成两段之间的过渡，不改动原视频人物、构图、动作和声音。
```

## 8. 完整白模示例

界面设置：目标时长 30 秒；画幅和分辨率按发布平台选择。下面代码块才是提交提示词。

```text
只参考@视频1的第一人称运镜、动作顺序、角色动线、左右站位和道具轨迹，人物外观、颜色与材质以@图1和@图2为准。@视频1中右前方模型对应@图1的角色甲，左前方模型对应@图2的角色乙；@音频1作为角色甲音色，@音频2作为角色乙音色，角色乙声线明显比角色甲低。

第一人称视角我，镜头代表我的视角；我在临海石质庭院里观看两名角色完成一次投掷游戏。午后自然光，石材、陶器和木制道具呈现真实纹理、自然阴影与接触重量，镜头保持轻微手持呼吸感。

0—4秒：我的左手和右手从画面下方扶正陶壶，镜头随我抬头，把右前方的角色甲和左前方的角色乙收入同一画面。角色甲面向角色乙，举起三支木筹，用明亮直接的声音邀请他参加游戏；角色乙低头整理手中的护具，嘴部闭合。

4—9秒：我的双手停在画面下沿，镜头保持两人和陶壶同框。角色乙抬头看向壶口，再看向角色甲，用低沉平稳的声音说只剩十分钟；说话时下颌收紧、嘴部小幅开合。角色甲立刻展开三支木筹，抬起眉部回应三局定胜负。

9—14秒：我的左手扶住壶口，右手抬起做开始手势，镜头随右手向右轻摇。角色甲双脚站稳，只投出一支木筹；镜头跟随木筹落向壶口，木筹敲到壶沿后落在石地上。角色乙转头看向落地木筹。

14—21秒：我的右手落回画面下沿，镜头先随木筹下沉，再转向左前方。角色乙弯腰拾起同一支木筹，站回投掷线后只投掷一次；镜头跟随木筹进入陶壶，壶底发出一声短促回响。角色乙把空着的手伸向角色甲，角色甲把下一支木筹放入他的掌中。

21—26秒：我的双手重新扶住壶口，镜头回到陶壶中央。角色甲把剩余木筹交给角色乙，随后放下双臂；角色乙接住木筹并逐支排齐。我开始把陶壶向自己这边收，镜头随双手轻轻下沉。

26—30秒：我的双手停在壶口上方。角色乙重新站回投掷线，握住下一支木筹，看向壶口，用低沉平稳的声音说还有七分钟；只有角色乙动嘴。角色甲在右前方举起双臂，我的双手立刻停住，镜头停在下一支木筹、陶壶和两名角色的反应上。

整段都是我眼睛看到的画面；我的双手在每个时间片持续入画并执行正文动作。角色甲始终在右前方，角色乙始终在左前方，两人各自保持外观；每次只投掷一支木筹，手部和道具归属清楚。画面里的主要角色只有角色甲和角色乙，只有当前说话角色动嘴，台词就是正文这四句。全段声音是海风、护具轻响、木筹敲击、陶壶回响和两人的对白，持续到最后一秒，画面是干净的影像。人物、道具、场景、光线和声音保持连续。
```

## 9. 完整三渲二多镜头示例

出自《兜风日》第八批“进门 v4”，按用户意见改定后出片通过。界面设置：全能参考、21:9、720P、30 秒；附五张角色设定图、一张餐厅场景图和两条声音参考。

用户意见：“回到家的对白太干瘪了可以思考一下关联一点互动”。改法：对白改成白和马格努斯四轮来回，内容是迟到、带回来的蜜瓜包、白说下次去海边（呼应开头的电话）、马格努斯说考虑考虑；罗尔夫加了带金属面甲的头部参考图。

看点：六段骨架齐全；位置段写清每个人和每件道具；声音段先交代四轮结构和谁闭嘴；每句台词都点名声音参考；说话的镜头写“画面里只有某人”；环境声写到结尾。

日语台词在这支片子里通过了审核，但在另一个项目里曾被以“版权”拦下；被拦时换成英文或中文台词。

<!-- validated-example-start -->

```text
@图1 马格努斯。@图2 白。@图3 罗尔夫的全身和服装。@图4 罗尔夫的头部特写：正面和两个侧面。他的脸和脸上的金属面甲照这张。@图5 阿尔克。@图6 餐厅。@音频1 白的声音参考：粗犷沙哑的中低音成年男声。@音频2 马格努斯的声音参考：低沉放松的成年男声。

三渲二赛璐璐动画，画面干净。秋天的夜晚，室内。餐桌上方一盏暖黄色的吊灯，灯光在桌面上照出一个明亮的圆；房间四周是安静的蓝灰色，窗外是深蓝色的夜和小镇的灯。整段画面从头到尾都是这盏吊灯的暖色光。

位置：整段都在同一间餐厅里。长方形餐桌在房间中央，桌子正中是一只盖着盖子、冒着热气的砂锅，桌上摆着四副碗筷、四只玻璃杯、几碟菜和一只面包篮。白坐在桌子左端的椅子上。阿尔克是成年人的身高，站在桌子后侧靠左的位置。罗尔夫坐在桌子后侧靠右的椅子上，坐姿端正。玄关的门和矮柜在房间的右侧。马格努斯的座位是桌子右端的椅子，紧挨着罗尔夫。马格努斯的红领巾结上别着一片金黄的银杏叶。四个人各自保持自己参考图里的样子和身高。开头马格努斯从右侧的门走进来，右手拎着一只牛皮纸袋，左臂夹着头盔；纸袋里是他带回来的一个蜜瓜包。

声音：这一段的对白是日语，白和马格努斯一人一句轮流说，一共四轮：白先说，马格努斯答，白再说，马格努斯再答。白的每一句都用白的声音参考的音色，低沉、粗犷、沙哑的成年男声，语速从容；马格努斯的每一句都用马格努斯的声音参考的音色，低沉放松。阿尔克和罗尔夫全程闭着嘴，用表情回应。

0–4秒：全景，镜头固定。白靠在椅背上，椅子的前腿翘起一点，尾巴在椅子后面一甩一甩；罗尔夫把筷子一双一双摆正；阿尔克把一盘菜放到桌上。右侧的门打开，马格努斯走进来，右手拎着牛皮纸袋，左臂夹着头盔。三个人一起转头看向门口。

4–9秒：镜头切到白的近景，四分之三侧脸，他坐在桌子左端同一个位置。他靠着椅背，抬起下巴，咧嘴一笑，露出虎牙，用白的声音参考的音色，低沉沙哑、带着笑意，慢悠悠地说，日语：「遅えぞ、マグノス。腹ぁ減ってんだ、こっちは。」

9–15秒：镜头切到门边的矮柜前，中景，画面里只有马格努斯。他把头盔放到矮柜上，嘴角一扬，用马格努斯的声音参考的音色，低沉放松地说，日语：「……ただいま。」他从纸袋里拿出一个装在透明包装袋里的蜜瓜包，朝餐桌左端轻轻一抛，接着说，日语：「ほら、土産だ。」

15–21秒：镜头切回桌子左端的白，中景。蜜瓜包从画面右侧飞进来，他一只手稳稳接住，耳朵一下竖起来，尾巴一甩，凑近闻了闻，眼睛发亮，用白的声音参考的音色，低沉沙哑、带着笑意，慢悠悠地说，日语：「お、メロンパン！」然后他拿着蜜瓜包朝马格努斯的方向一指，眯起眼睛，接着说，日语：「……次は海だからな。」

21–26秒：镜头切到桌子右端，近景，画面里只有马格努斯。他走到桌子右端拉开椅子坐下，往椅背上一靠，朝白的方向瞥了一眼，嘴角慢慢扬起，用马格努斯的声音参考的音色，低沉放松地说，日语：「……考えとく。」他的尾巴在椅子后面慢慢摆了一下。

26–30秒：镜头切到餐桌前的中景，镜头固定，四个人都在画面里：左端是白，后侧是站着的阿尔克和坐着的罗尔夫，右端是刚坐下的马格努斯，桌子正中是冒着热气的砂锅。白“嘁”地笑了一声，低头去撕蜜瓜包的包装袋；罗尔夫把一双筷子递到马格努斯面前；阿尔克双手垫着布握住砂锅的盖子，转头看向白，眉毛一挑。

环境声：开门声；头盔放到柜子上的一声轻响；包装袋的沙沙声；椅子挪动的声音；砂锅咕嘟声；碗筷的轻响。
```
