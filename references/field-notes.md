# Seedance 2.5 实战经验

这些规则来自多轮 15 秒、30 秒、第一人称、多人、音频和白模项目的出片复盘。它们是通用经验，不替代平台当前能力说明。

## 1. 指令密度

提示词密度与稳定性通常成反比。只留下模型无法从素材和上下文自行得到的信息。

- 一段只放一名角色的主要动作或一次情绪变化；这个动作可以写成一串连续的小动作。
- 其他角色保持简单的背景动作或反应。
- 复杂动作拆成准备、执行、接触、结果。
- 快速手部特写容易产生多手、多指和道具增殖；让手部动作慢、单一、归属明确。
- 同一句不要同时要求固定镜头和环绕、稳定站立和快速位移等矛盾动作。

抽象句“画面很有电影感”不占据明确执行槽位，但也几乎不提供控制。把它换成镜头、光线、材质和物理行为。

## 2. 时间轴与连续性

30 秒不代表六段五秒。先写动作节点，再按每个节点真正需要的时间分配区间。

连续性检查顺序：

1. 上段结束时每个角色在哪里、手里有什么、朝向哪里。
2. 下段开始是否直接继承这些状态。
3. 道具是否仍是同一个，数量是否变化。
4. 镜头为何转向新的主体，是否有视线、声音或动作触发。
5. 光线、天气和背景人物是否保持合理运动。

不要在每个时间段重新介绍场景和角色。重复介绍会诱发位置重置和身份重绘。切镜后用一句话确认地点即可（“地点还是护栏边停车的位置”），布局只在位置段写一次。

## 3. 素材映射

素材映射是多模态稳定性的第一道门槛。

- 用文本绑定素材；不要只在图片上写角色名。
- 每个参考视频都说明“照它的哪一部分”，以及其余部分以哪个素材为准。
- 一张图含多个视角时，主体多会降低稳定性；优先拆成多张单视角图。
- 多角色采用清单式映射，角色、音色、道具和模型一一对应。
- 参考图已经精确锁定外观时，正文只写动作、表演和变化，不再复述整套服装。

错误：

```text
参考这些图和视频生成。
```

正确：

```text
@图1只参考角色甲外观；@视频1只参考镜头和动作节奏，人物外观以@图1为准；@音频1作为角色甲音色。
```

## 4. 第一人称 POV

第一人称提示词首先要建立“镜头就是我看到的画面”，再让角色进入画面。

- 第一人称声明放在第一句，避免被其他设定挤到后面。
- 正文只写“我看到了什么”，不写镜头外发生的秘密动作。
- 视线转向要有原因：说话声、道具落地、角色伸手或环境变化。
- 要求双手连续出现时，每段都写双手的位置或动作。只写一次“全程有双手”不足以保证连续。
- 双手分工越少越稳；每只手只承担一件事。
- 需要角色显得高大时，用真实仰视和取景关系，不堆“巨大、肩宽背阔”等比例放大词。
- 动态大位移会增加“我”被实体化成第三人称角色的风险。优先让其他角色走进画面完成互动。
- 轻微手持呼吸感可以保持镜头生命力，但每段仍应有清楚的视线或手部运动落点。

## 5. 多角色与对白

多人场景最常见的失败是串脸、互换站位、动作归属混乱和错误角色动嘴。

稳定配方：

1. 开头写一次相对站位。
2. 一段只给一名角色主要动作。
3. 所有动作点名角色，不用集体代词。
4. 说话人面向谁要写明；不写时容易默认看镜头。
5. 只有当前说话角色动嘴，其他角色写“嘴部闭合”或只给身体反应。
6. 每个角色绑定独立音色，需要时加入相对音高或音色锚。

### 台词写法

括号里写可执行表演：

```text
角色甲（声音明亮直接；面向角色乙，眉部抬起，嘴部自然开合）说：“现在开始。”
```

避免文学化心理描写：

```text
角色甲（仿佛终于等到命运回应，眼中燃起希望）说……
```

台词要短，尽量让动作承担信息。外语台词直接写目标语言原文；字幕文本需要固定时，紧跟台词写出完整字幕。

## 6. 白模

无外观的人类默认白模足以承担站位、动作和镜头预演。最终角色外观可由参考图、角色引用或文字设定补全。

粗颗粒度白模的关键不是模型细节，而是：

- 相机轨迹和镜头高度。
- 模型左右、前后与远近关系。
- 手臂、身体和道具的运动顺序。
- 道具轨迹、接触点和落点。
- 每个动作发生的真实时间。

写提示词时：

1. 点名要继承的动态维度。
2. 明确白模模型与最终角色的映射。
3. 写明最终外观和材质以角色参考图为准。
4. 最终剧情按镜头可见内容重新写，不把白模当故事说明的替代品。
5. 文本动作与白模动作保持一致，避免两个控制信号互相对抗。

细颗粒度白模重点在材质和光影。上传前移除轨迹线、坐标线和相机锥体。

## 7. 真实电影质感

“卡通感”和“AI感”通常来自材质、光线和人物设计缺少现实依据，而不是缺少“realistic”一词。

写清：

- 皮肤、毛发、石材、木材、金属、陶器和织物的真实微观纹理。
- 光源方向、软硬程度、接触阴影和反射强度。
- 重量、惯性、摩擦、碰撞后的声音和物体结果。
- 自然白平衡、合理景深、主体清晰度和不过度锐化。
- 路人存在时逐个定义体型、服装轮廓、年龄区间、工作状态和独立动作，避免背景人群糊成重复人形。

干净画面用正向结果描述：

```text
清晰锐利、自然白平衡、真实材质、干净高光、暗部平滑干净。
```

否定写法会损伤细节，`no noise, grain` 这种串还容易把 `grain` 当成正向概念。正面写法见 `positive-prompting.md` 第 1 节。

## 8. 声音

把声音当独立时间线处理：

- **对白**：说话人、音色、语气、语言、嘴部动作。
- **环境音**：风、雨、人群、房间底噪。
- **动作音效**：脚步、布料、金属、碰撞、道具回响。
- **BGM**：有无、风格、强弱、何时降低或停止。

当台词重要时，BGM 保持低于人声；台词前降低音量。需要纯净底片时明确保留哪些声音，而不是笼统写“无声音”。

参考音色最好清晰、无混响、无音乐。多人音色逐人绑定，不共用模糊的“参考这些音频”。

## 9. 编辑与延长

### 编辑

修改指令必须回答五个问题：

1. 改哪里？
2. 改什么对象？
3. 从什么变成什么？
4. 何时生效？
5. 哪些内容保持不变？

局部消除还要写背景如何补全，以及不能留下的残影和闪烁。

### 延长

延长从原视频末帧开始。先写继承状态，再写新增动作。避免重新介绍人物和场景，否则模型可能把延长当成新片开头。

需要转场时选择单一触发：前景遮挡、动作接力、相似形状、焦点推进或声音先行。转场前后保持运动方向和视觉重心。

## 10. 翻车诊断

| 症状 | 常见原因 | 优先修复 |
|---|---|---|
| 后半段跑偏 | 时间片内容太少或状态未承接 | 补结果状态和下一段起点 |
| 动作像快进 | 单段动作过多 | 拆段或删动作 |
| 多手、多道具 | 手部分工密集、交互重叠 | 每只手只做一件事，减少同帧交接 |
| 角色串脸 | 素材映射模糊、多人同时行动 | 逐人绑定，一段一名活动角色 |
| 错误角色说话 | 未写说话人朝向和嘴部状态 | 只让当前角色动嘴，点名其他人反应 |
| 白模外观残留 | 未声明白模只作动态参考 | 写明参考维度，外观材质以角色参考图为准 |
| POV 变第三人称 | 镜头身份不够早、大位移过多 | 第一行钉 POV，让角色进入镜头 |
| 画面卡通或塑料 | 只有抽象风格词 | 补材质、光源、皮肤纹理和物理反馈 |
| 随机字幕或 BGM | 声音与字幕通道未明确 | 分通道列出全段的声音，写“画面是干净的影像” |
| 时间控制失效 | 时间轴有空隙、重叠或机械过载 | 运行校验器并重新分配动作容量 |
