# GPT Image 提示词技巧

给 Seedance 准备角色设定图、场景图和机位图时，用 GPT Image 出图。本文合并两类来源：OpenAI 官方的出图提示词指南（2026-10 查阅），以及《兜风日》约一百六十张出图的实测规则（`positive-prompting.md` 第 8—10 节）。两者冲突时以实测规则为准，冲突处在文末列出。

来源：

- OpenAI Cookbook：[GPT Image Generation Models Prompting Guide](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide)
- OpenAI 文档：[Image prompting](https://developers.openai.com/api/docs/guides/image-prompting)

## 1. 结构

- 按“用途 → 场景 → 主体 → 关键细节 → 画风”的顺序写，复杂的图用带标签的短段落，例如【画面】【画风】。
- 开头一句写用途，它决定精细程度：“这是马格努斯的角色设定图，用作视频生成的角色参考。”
- 人物写清取景和比例：“全身入画，从头顶到脚底都在画面里”。兽人角色的脚常被裁掉或画错，这句要写。
- 走写实路线时直接写“照片写实”；走三渲二路线时写画风段，见 `positive-prompting.md` 第 8 节。

## 2. 参考图

- 每张图编号并写清用途：“图1是马格努斯的官方立绘，他的脸、毛色和体型照这张；图2是画风参考，线条和上色照这张。”
- 写清几张图之间的关系：“服装和画风以图2为准，脸以图1为准。”
- 第一张定稿的设定图就是“角色锚点”，之后的派生图（戴盔、睡衣、比例图）都把它附上。同一角色换姿势时，附上已定稿的图并写“同一个角色，换成某某姿势”，比只靠同一段文字重新生成更稳（社区实测）。
- 画风写到具体的年代和类型，例如“赛璐璐动画电影的背景美术”“两阶明暗的硬边上色”。笼统的“动漫风”会落到模型默认的柔和渐变上色。
- 设定图的每个视图都点名（正面全身、背面全身、头部特写），只写“角色设定图”时模型会自己挑角度。
- 发带、伤疤位置、袖口标记这类小细节在每次生成之间会漂，出图后逐件对照。
- 每条提示词都重写一遍角色的固定特征（配色、标志性服饰、耳朵和尾巴形状）。“和上一张一样”这类说法管不住细节。

## 3. 修改与迭代

- 一轮只改一件事，同时列出要保持原样的部分：“只把两只袖子改成纯黑色皮革；脸、毛色、版式、光线和其余服装保持原样。”每一轮都重写这份保持清单。
- 必须一像素不变的区域（比如已经通过的头部），出图后把通过的区域贴回原图，不靠反复编辑去保。
- 用户的默认流程是从原始参考全新生成，不在失败图上反复局部修改；局部编辑只用于明确的小改动。

## 4. 质量与尺寸

- 特写肖像、对身份敏感的修改、细小的图案用 medium 或 high 质量。
- Codex 和 ChatGPT 内置的出图用的是 gpt-image-2（官方文档原文，2026-10-24 核对）。会话里选的对话模型只负责调度，不决定出图模型。要用更新的出图模型，得走 API 单独指定。
- 宽高比上限约 3:1，21:9（约 2.33:1）在范围内。经 Codex 出图时，21:9 原图是 1916×821，16:9 是 1672×941。
- 透明背景要用透明背景参数并输出 PNG 或 WebP，出图后检查透明通道。画出来的灰白棋盘格是图案，透明度为零，上传视频平台前要换成纯白背景。

## 5. 文字

整个项目的招牌、包装都画成纯色块和几何图形，一般用不到文字。需要文字时，把原文放进引号，写清位置、字体和颜色，难拼的词逐字母拼出来，出图后核对拼写。

## 6. 与实测规则冲突、没有采用的

| 官方建议 | 没有采用的原因 | 实测写法 |
|---|---|---|
| 用 “no watermark”“no extra text” 这类排除句 | 用户 10-04、10-11 两次确认否定词损伤细节、会被其中的名词带偏 | 改写成想要的样子，如“招牌上的图案都是纯色块和简单的几何图形” |
| 用 “do not redesign the character” 防止跑偏 | 同上 | 写“角色的长相、毛色和服装照图1” |
| 写 “photorealistic” 开启写实模式 | 三渲二路线会被它拉向写实 | 只在超写实路线里写 |
