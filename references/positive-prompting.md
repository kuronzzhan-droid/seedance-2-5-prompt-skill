这些规则来自《兜风日》三渲二短片的复盘：即梦 Seedance 2.5 全能参考 21:9、每条 30 秒，约 40 条 720P 和几轮 480P 样片；图片侧是 GPT Image 约一百张场景图和约六十张角色图。它们是这两个模型上的观察，换模型时重新验证。

## 1. 只写正面描述

否定句和负面提示词会损伤细节，也不提高美感；模型还会被否定词里的名词带偏。视频和图片提示词都只写画面里有什么，末尾也不加否定的兜底句。想排除的东西就不写，或改写成想要的样子。这条同样适用于交给其他模型起草的提示词初稿，验收时照它检查。

| 想要 | 正面写法 |
|---|---|
| 画面里没有人物 | 只有空旷的草原、石墙和天空 |
| 场景里没有人和车 | 留给角色之后入画的空镜环境图，过道空着，整个画面安静 |
| 招牌和包装上没有字 | 招牌、路牌、包装上的图案都是纯色块和简单的几何图形 |
| 画面干净没有颗粒 | 大面积的表面像色纸一样平整，像用一桶颜料一次填满 |
| 手部特写只有一只手 | 画面里是他的一只右手和右前臂 |
| 这一镜没有别人 | 画面里只有马格努斯 |
| 这一条没有对白 | 全段是环境声和动作声 |
| 别人不说话 | 阿尔克和罗尔夫全程闭着嘴，用表情回应 |
| 参考视频只取动态 | @视频1的运镜、动作顺序和站位照它来，人物外观以@图1为准 |
| 第一人称不切第三人称 | 整段都是我眼睛看到的画面，画面下沿是我的双手 |
| 无字幕、无背景音乐 | 声音是海风、脚步和两人的对白，画面是干净的影像 |

只删掉否定词还不够。一版全正面但只列部件的角色设定图仍然“不太好看”；补上整体观感、姿态、脸和配色点缀四段之后，出图才有姿态和魅力。

自查：通篇搜索“不要、没有、无、不是、禁止、避免、不参考”，每一处都改写成画面里有什么。

## 2. 写看得见、数得清的东西

模型照字面画。“好看、自然、合理”无从下手；能数、能指的才管用。

- 形状写数量：树冠“三到五个圆润的大色团”，树影“两三块边缘圆润的大形状”，落叶“一片平涂的色块，边缘散着十来片”。
- 位置用画面分区或身体部位：“画面上半部分是……下半部分是……”“车把在他腹部前方，车轮的顶端和他弯着的膝盖差不多高”。
- 光用方向：“太阳在画面右上方的画外，光从右上方照来”。

## 3. 参考图的取舍与命名

- 参考图比文字有力。附了方向相反的图，文字拗不过来；附了画错的旧图，新图照旧图画。
- 每张图过一遍：它和要的画面有没有矛盾。有就不附，或先裁掉矛盾部分。
- 每张图一句说明“这是什么、照它的哪一部分”：“罗尔夫的头部特写：正面和两个侧面。他的脸和脸上的金属面甲照这张。”
- 给参考图起短名字，后面直接叫它：“构图和‘家门口’一致”“人和车的比例照‘骑车比例图’的正面”。
- 动笔前按原始分辨率裁出要画的部位放大核对。直线和折角是护具，蓬松尖角是毛。
- 每次重写都记“用户原话 → 改了什么”，下次改同一条时不会把修好的地方改回去。

## 4. 30 秒主动镜头结构

一条 30 秒，正文约一千三到一千五百字，附六到八张图加一两条声音。固定六段：

| 段 | 写什么 | 例 |
|---|---|---|
| 引用 | 每张参考一个 @ 引用加一句说明 | @图3是骑车比例图，他骑在摩托车上时人和车的大小比例照这张 |
| 画风和光线 | 三渲二；时间；光源在哪、照到哪 | 太阳很低，在街道一侧的画外，暖金色的晨光从街上照向车库 |
| 位置 | 场景布局；每个人、每件道具在哪；整段是否同一地点；路线 | 白坐在桌子左端的椅子上，阿尔克站在桌子后侧靠左的位置 |
| 声音 | 几句台词、谁说、用谁的声音参考、语气；谁闭嘴 | 这一段有三句日语自言自语，都是马格努斯说的，声音很轻 |
| 按秒分镜 | 五到九个镜头 | 3–8秒：镜头切到他的侧前方近处，近景，慢动作…… |
| 环境声 | 按出现顺序列出，写到最后一秒 | 引擎熄火；风声；叶子的沙沙声；一声长哼和一口长长的呼气 |

角色长相交给参考图，正文只写名字。

单个镜头三到七秒，连续跟随或环绕长镜头七到十二秒。每个镜头按顺序写：

1. 时间段：`11–18秒：`
2. 镜头在哪：景别、机位、高度、朝向、动不动。
3. 地点是否同一个：“地点还是护栏边停车的位置”。
4. 怎么接上一镜：“承接上一镜，他已经下了车，站在摩托车旁”。
5. 正在做什么：一串小动作，一个动词接一个动词。
6. 会动的细节，至少一两个：尾巴、耳朵、被气流带动的领巾和鬃毛、落叶、蒸汽、高光点。
7. 神态：眼睛、耳朵、嘴角各做了什么。
8. 台词（有的话）。

“主动”指角色在每一镜里都在做事：

- **亮相**时已在下一步动作里。卷帘门升起时他骑在车上、发动着、手握车把；站在车旁就“纯站着太呆了”。
- **连续镜头**写明“一个连续的环绕长镜头，一镜到底”，再按秒写镜头转到哪、看到什么。
- **慢慢露出**写出顺序：先露出前轮和亮着的圆头灯、踩地的脚爪，再露出……，最后露出他的脸和鬃毛。
- **骑行后跟拍**写“他和摩托车一直在画面中央，看得清夹克背后的爪印、向后飘的红领巾和尾巴末端的簇毛”。只写路和景会拍成空路。
- **到达**用后跟拍，目的地在正前方越来越近。
- **换地点**：让他走过去或骑过去、镜头跟着；或切到写明机位和构图的新镜头，让他“从画面右侧沿街驶入画面”。
- **日常琐事**一个手部特写带过：手机贴上感应区“嘀”一声。
- 需要他一直在画面里就写：“整段的每一个镜头里都有马格努斯”。

示例镜头：

```text
11–18秒：机位在车库门外的街上三四步远，高度和摩托车的头灯一样高，微微仰拍，镜头固定。地点还是自家车库门口，承接上一镜。他一条腿跨过摩托车坐上去，坐垫一沉，避震轻轻一弹；他把头盔架在身前的油箱上，拇指按下启动键，圆头灯亮起。红领巾被引擎的震动带得轻轻抖，尾巴末端的簇毛在坐垫后侧扫了一下。光照到脸上，他眯了一下眼，耳朵轻轻一转，嘴角一边扬起，露出一点犬齿。
```

难的机位先出一张那个机位的空镜参考图，写“构图和‘车库门低机位’一致”，再把“镜头在哪一侧、光在哪一侧、人在哪一侧”各写一遍。卷帘门这一镜只靠文字反复抽了三版都反了，附上机位空镜图后第一条就对。

## 5. 光线与位置

- “逆光”会在角色头顶生成一团光晕。改写光源在画外哪一侧。
- 室内写一句“整段画面从头到尾都是这盏吊灯的暖色光”，各镜色温才一致。
- 位置段保证切镜后东西还在原位：车停在哪、头盔挂在哪、纸袋在哪只手里、谁坐哪把椅子。
- 赶路的段落写成“位置和路线”：从哪出发、经过什么、每段路怎么接下一段、终点在路的哪一侧。
- 人和大件道具同框时用身体部位写比例，并附比例图。

## 6. 台词与声音

- 一条最多绑两条声音参考。四人戏拆成两条，每条两人说话。
- 每句台词都点名声音参考：“用白的声音参考的音色，低沉沙哑、带着笑意，慢悠悠地说，日语：「遅えぞ、マグノス。」”
- 语气写平常的。写“大声说”音高会抬高三四成。
- 一人一镜：说话的镜头写“画面里只有马格努斯”或某人的近景。
- 声音段先交代结构：谁先说、谁答、一共几轮。
- 容易读错的汉字写成假名，如「飯」写成「メシ」。
- 结尾的声音写到最后一秒：“笑声和碗筷声一直持续”。
- 对白有来有回，和前面的事有关联。

## 7. 相邻两条的衔接

- 前一条结尾的姿势、位置、手里的东西，原样写进后一条开头：“左臂夹头盔、右手拎纸袋”两边各写一遍。
- 结尾动作要做完：“背对着树干坐下，身体往后一倒，仰面平躺进落叶里”。
- 后一条用近景或特写开头，避免两个同场景全景首尾相接。
- 模型容易错、要点名的：掀起面罩后全盔变半盔、头盔颜色、尾巴簇毛、耳朵形状、手指和手的数量、包装与招牌文字、脚（脚爪还是靴子）、设定图里没有的角度（没有正脸参考就用四分之三侧脸）。

## 8. 21:9 三渲二画风

**视频**：21:9 在即梦界面设置，正文写画风本身：

```text
三渲二动画质感：角色是两阶明暗的硬边上色，细描边取底色加深一档的同色系，鬃毛是几大簇成块的毛，皮革是平整的黑色加一条硬边高光带。太阳在画面右上方的画外，暖金色的光从右上方照来。
```

**图片**：GPT Image 没有比例参数，比例直接写进正文：“21比9的超宽横幅”“画面比例16比9横图”。经 Codex 出图时，包装语写“出图提示词直接使用下面的原文，全文照用，保持原文正面描述的写法”，并要求“按原始像素尺寸原样复制”（21:9 为 1916×821，16:9 为 1672×941）。

场景图的统一画风段（六轮定稿）：

```text
赛璐璐动画电影的背景美术，干净、安静、通透。
疏密：画面以大而完整的色块为主。天空、路面、墙面、地面、远山这些大面积占画面的三分之二，每一块都平整安静；细节集中在一处视觉中心，其余地方留白，让眼睛休息。
形状：一切都用大形概括。一棵树的树冠是三到五个圆润的大色团，亮面一个颜色、暗面一个颜色；远处的树林是一条连续起伏的色带；云是两三朵轮廓圆润的大云；山是一层一层的平涂剪影。
影子：落在地面上的树影是两三块边缘圆润的大形状，像剪纸一样完整；建筑和栏杆的影子是干净的几何形。
落叶：地上的落叶是一片平涂的金色色块，色块边缘散着十来片画清楚的叶子；空中飘着三五片。
线条：近处的物体用细而利落的描边，线的颜色取所在色块加深一档的同色系；远景靠色块的边缘成形。
上色：平涂。每个面是一块均匀的颜色，明暗分两阶，亮面和暗面由一条清楚的硬边分开。天空是一道平滑均匀的渐变。
大面积：大面积的表面像色纸一样平整，像用一桶颜料一次填满。路面是一整片均匀的蓝灰色，地面是一整片均匀的浅灰色，墙面是一整片均匀的浅色，夜空是一整片均匀的深蓝色；这些面上落着的是车道线、影子和光斑这样轮廓清楚的大形状。
配色：每张图三到四个主色，颜色明亮柔和、协调统一；青绿色作为点缀色小面积出现。
构图：21比9的超宽横幅，有一个明确的视觉中心，前景、中景、远景三层分明，画面有大片留白。
画面内容：留给角色之后入画的空镜环境图，画的是环境、建筑、植物、物件和光影，整个画面安静。招牌、路牌、包装和地图上的图案都是纯色块和简单的几何图形。
```

每一句对着一个问题：

- 材料名会招颗粒。“柏油、水泥、混凝土、灰泥”写进去路面就出颗粒；只写颜色和平整度后高频残差从 1.1 降到 0.3。
- “斑驳、一块一块、厚厚一层、成簇带尖角”招碎形状，换成写死数量的大形状。
- 把角色设定图作为画风参考一起附上，场景线条和上色更接近角色。
- 复用画风段时，“大面积”和“视觉中心”两句按当前这张图的内容改。
- 二维动画风格下，模型会自己给物体加立体光影和金属反光（社区实测）。金属、玻璃、镜面写成“纯色平涂的平面，带一条窄窄的硬边高光”，和罗尔夫面甲的写法一样；道具尽量选卡牌、布料、木头这类本来就平的东西。

## 9. 角色设定图

**版式**：16:9 横图，纯白背景，左边正面全身，中间背面全身，右边头部特写。正侧背三视图会把人画矮。

段落顺序：

1. 参考图是什么、以谁为准。
2. 版式：三部分各是什么，头部特写画到哪、什么表情。
3. 身材比例：“约八头身，腿的长度占身高一半以上，肩宽腰窄，头相对身体偏小。两个全身像身高完全一致，从头顶到脚底撑满画面高度，脚底在同一条水平线上。”
4. 角色：物种、毛、眼睛、耳朵、爪、尾巴。
5. 毛色分布：正面和背面分开写。
6. 服装：从上到下逐件写，颜色和材质跟着每一件。
7. 背面视图：背后的图案、露出的后腰、尾巴从哪伸出。
8. 画风：两阶明暗硬边、细描边取底色加深一档、鬃毛几大簇成块、皮革平整黑色加硬边高光带；光从左上方来。

要好看再加四段：整体观感、姿态（重心落在一条腿上、手上有个小动作）、脸（吻部、眼形、表情）、配色点缀。

示例开头：

```text
画面比例16比9横图，纯白背景。这是马格努斯的角色设定图，以附图的官方立绘为准。画面分三部分：左边是正面全身像，中间是背面全身像，右边是头部特写，画到锁骨，表情是一边嘴角扬起的轻松笑。约八头身，腿的长度占身高一半以上，肩宽腰窄，头相对身体偏小。两个全身像身高完全一致，从头顶到脚底撑满画面高度，脚底在同一条水平线上。
```

其他图：

- **兽人的腿和脚**照原画逐个写：弓足还是直腿、脚上戴什么、脚趾露不露。弓足写出折线（小腿向后斜，脚踝高高抬离地面，脚趾和前脚掌着地），并附腿脚原画特写。
- **纠正画错的部位**：参考里只放画对的原图；把部位拆成范围、轮廓、颜色、质感四段；再写它和周围的质感对比；开头标“最重要，三个头像保持一致”。
- **头部三视图**：三个头像大小一致、眼睛在同一水平线；正面写“吻部正对镜头向前伸出，带着清楚的透视缩短”。
- **比例图**：两个视图并排，比例用对应关系写，“坐垫在他大腿根的高度”。
- **派生图**（戴盔、睡衣）：同时附原始立绘和已定设定图，写明哪张管什么。
- 出完逐件对照立绘；版本之间多出来的小标记，下一版把那个部位写死（“两只袖子是纯黑色皮革”）。

## 10. 场景图

场景图只画环境，角色靠独立设定图绑定。结构是【画面】加【画风】两段。【画面】依次写地点季节时间、机位（在哪、多高、朝哪、景别）、画面分区各有什么、光从哪来照亮哪里、主色与两三处点缀色。【画风】用第 8 节的统一段。

- 同一地点多张图：附上已有那张，写“和附图是同一家店”“同一机位”。
- 一个地点拆成多条视频时，先出一张定布局的全景，每条都附。
- 难的机位先出机位空镜图，【画面】按“上半部分、下半部分、最下方”分区。
- 出图后检查：四个底角的假签名、设计里没有的东西、同一建筑在几张图里是否一致、角色比例有没有变矮。

## 11. 内容被拦时的降级写法

提交被平台拦下时，按顺序处理：

1. **二分法定位**：删掉一半正文再提交，逐步缩小到触发的句子，记进项目敏感词表。
2. **换掉已知触发项**：日语台词曾以“版权”被拦，同一提示词换成英文或中文台词后通过；角色名放进台词也可能撞版权过滤，台词口语里用“他”。
3. **换成更日常的动作**：高风险接触改成揉头、打滚、搓搓耳朵这类大白话动作；删掉颈窝、胸口、指腹这类身体部位细描词。
4. **从结果状态开场**：换衣、更衣剧情直接从“已经换好泳装坐在床边”开场，过程留到之后再拍。
5. **删内容声明句**：“无暧昧、无裸露”这类声明句本身会引雷。用正面写清基调与可见内容，例如“喜剧照顾向的日常，他全身覆盖蓬松的绒毛，穿着宽松的泳裤”。
6. **降级方案写在提交正文之外**：在制作注记里预写“镜3若被拦或翻车，改成他伸手把我从池边拉进怀里”，提交正文始终是可直接粘贴的正面描述。

示例改写：

```text
原句：我帮他脱掉外套，手指顺着颈窝滑到胸口。
降级：他已经换好宽松的泳裤坐在床边，我搓搓他的头，揉揉他的耳朵，他眯起眼睛往我手心里蹭。
```

## 12. 出片问题对照表

| 出片问题 | 提示词改法 |
|---|---|
| 机位反了 | 出机位空镜图；写镜头、光、人各在哪一侧 |
| 人和车比例怪 | 出比例图；用身体部位写比例 |
| 手部特写多出一只手 | “画面里是他的一只右手和右前臂” |
| 角色呆站 | 亮相时已在动作中；每镜加会动的细节 |
| 下一秒换了姿势或地点 | 写明地点是否相同、动作怎么接；结尾动作做完 |
| 目的地突然出现 | 切到写明构图的固定机位，他从画面一侧进来 |
| 骑行镜头里没有人 | “他和摩托车一直在画面中央” |
| 头顶有光晕 | 去掉“逆光”，写光源在画外哪一侧 |
| 正脸奇怪 | 补有正脸的头部参考图，或改用参考图里有的角度 |
| 声音串到别人身上 | 每条最多两条声音参考；每句点名 |
| 音高偏高 | 去掉“大声” |
| 读错字 | 写成假名 |
| 动嘴的人不对 | 一人一镜 |
| 后半段静音 | 写明声音持续到结尾 |
| 路面墙面有颗粒 | 删材料名，写颜色和平整度 |
| 提交被拦 | 按第 11 节降级 |
