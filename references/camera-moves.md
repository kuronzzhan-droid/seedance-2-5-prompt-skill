# 运镜手法

写 Seedance 2.5 多镜头片时选运镜用。整理自 2026-10-24 的官方和社区教程、一份 82 条社区热门提示词合集，以及用户自己的两次对比测试（D6「潮息印」和瓦胡德、肯尼V 的角色 PV）。教程大多是二手经验，标了“实测”的才是用户自己跑过的，每组只跑过一两条，当方向看。

## 1. 基本规则

1. **一个镜头一种运镜，写在这一镜的最前面。** Runway 的 2.5 指南说超过 4 秒的镜头能组合两种运镜，先按一镜一种写，稳了再试组合。
2. **写清起点、走法、终点。** 只写“推近”，推多快、推到哪都由模型定。写成“镜头从中景开始，用五秒匀速推到他胸口以上”。
3. **速度用时长卡住。** “dramatic、epic、fast”这类词会让镜头加速、乱转（教程说法，没有测试数据），写“匀速”“用整整六秒”。“电影感”不是运镜，模型没法执行。
4. **第一段写明“一共 N 个镜头”**，防止模型自己切镜。
5. **说话的镜头收到胸口以上，画面里只有说话的人。**（实测：D6 测试里只有这样写的那条拍全了脸。）
6. **追逐用第一人称，到扑倒或接触的那一下硬切第三人称。**（实测：PV 测试里第一人称的追逐最有临场感，第三人称更适合双人和特写；扑倒以后模型两次自己切成第三人称，干脆写明。）
7. **专业术语一个镜头用一两个就够**，堆多了会失控。

## 2. 运镜词典

| 运镜 | 提示词怎么写 | 适合什么戏 |
|---|---|---|
| 固定镜头 | 镜头固定，机位在桌子侧面，和人眼一样高 | 对话、悲伤、喜剧停顿 |
| 推近 | 镜头从中景开始，用五秒匀速推到他胸口以上 | 心动、意识到什么、开场 |
| 拉远 | 镜头从两人背后开始，匀速后退并升高，拉到整座城 | 揭示规模、收尾 |
| 横摇 | 机位不动，镜头从左向右摇，扫过墙上一排挂钩 | 环顾、展示空间 |
| 上摇、下摇 | 镜头从两人的脸向下摇到膝盖和尾巴 | 顺着视线找细节、顺着东西落下 |
| 横移跟拍 | 镜头和他平行移动，保持在他左侧四步远，和他一样快 | 追逐、巡逻 |
| 前导跟拍 | 镜头在他前方倒退，和他保持同样的距离 | 冲向观众的追逐、下决心 |
| 环绕 | 镜头围着两人顺时针绕半圈，停在某人的正面 | 对峙、亲密 |
| 升降 | 镜头从穹顶上空十几米处，用六秒降到穹顶表面 | 进场、史诗 |
| 正俯拍 | 镜头在正上方，垂直向下拍 | 扭打、两人躺倒、影子的形状 |
| 仰拍 | 机位贴近地面向上拍 | 威压、恐惧 |
| 过肩 | 从他右肩后面拍向远处的屋顶 | 发现、对视 |
| 移焦 | 焦点从他的耳朵移到远处的塔窗 | 埋线索、两人的距离 |
| 手持 | 手持镜头，轻微晃动 | 追逐、慌乱；温情戏用固定或慢推 |
| 第一人称 | 第一人称视角，镜头就是他的眼睛，画面下方能看到他的两只手 | 追逐、沉浸 |
| 一镜到底 | 一个连续镜头，一镜到底；空间之间用“穿过、绕过”连接，最多三个空间 | 长段空间穿行 |
| 甩镜 | 镜头快速甩向右边，接到下一个画面 | 转场、追逐 |
| 匹配剪辑 | 上一镜的圆形穹顶，接这一镜画面同一位置的圆形灯罩 | 转场 |
| 慢动作 | 这一下是慢动作 | 扑倒、爆发的一瞬 |
| 希区柯克变焦 | 镜头后退，同时焦距推近，背景向后拉长 | 震惊（未实测） |
| 荷兰角 | 画面向右倾斜约十五度 | 不安、失衡（未实测） |

## 3. 按戏配运镜

- **追逐**：第一人称开场，接横移跟拍，再给一个固定的喜剧镜头。一镜三到六秒，结束用一个静止的镜头刹车。
- **扭打、压制**：先用正俯拍看清两个人的形状，再用侧面低机位拍两张脸慢慢推近，最后下摇到手、刀或尾巴。
- **心动**：慢推近，景深浅，背景虚化。耳朵、尾巴的动作单独给一个下摇或特写。说话收到胸口以上，一人一镜。
- **史诗、揭示**：拉远或升降，一镜给足六到八秒。声音先空一拍再起。
- **悲伤、静默**：固定镜头，门框、窗框把人框在画面里，人小，留白大，只给环境声。
- **喜剧**：固定中景，动作在画框里完成，反应留一秒。
- **对话**：正反打，胸口以上，一人一镜。两人同框时写清谁说话、谁闭着嘴。
